## 1. 研究背景与意义

### 1.1 研究问题

表面活性剂（surfactant）是一类具有两亲结构（亲水头基 + 疏水尾链）的分子，被广泛应用于日用化工、石油开采、制药、环境治理等领域。其关键界面性质包括：

| 性质 | 符号/含义 | 物理意义 |
|------|-----------|----------|
| **pCMC** | log CMC（临界胶束浓度对数） | 开始形成胶束的浓度，核心指标 |
| **pC20** | 表面活性剂效率 log(1/C20) | 使表面张力降低 20 mN/m 所需浓度 |
| **AW_ST_CMC** | CMC 时表面张力 | 表面活性剂降低表面张力的能力 |
| **Pi_CMC** | CMC 时表面压 = γ₀ − γ_CMC | 表面压，衡量界面吸附效率 |
| **Gamma_max** | 最大表面过剩量 | 界面吸附量的上限 |
| **Area_min** | 最小单分子面积 | 每个分子在界面上占据的最小面积 |

### 1.2 为什么需要机器学习预测

- 实验测定 CMC 等性质**耗时耗力**（需要表面张力仪、等温滴定量热等，逐分子测量）。
- 若能**仅凭分子结构（SMILES）快速预测**性质，即可实现高通量筛选与"先设计后实验"。
- 本项目对标文献数据集，构建**可复现、可解释、可部署**的完整预测流水线。

### 1.3 研究目标

1. 设计一套能充分刻画表面活性剂结构信息的**手工特征**（融合原子、键、药效团、反应性、两亲结构等多尺度信息）。
2. 系统性对比 **10 种回归模型**（7 种树模型 + 3 种深度模型）在 6 个目标上的表现。
3. 利用 **SHAP** 实现模型可解释性，回答"什么结构决定了 CMC 高低"。
4. 封装**预测 API**，实现"输入 SMILES → 输出性质"的即用功能。

## 2. 数据来源与预处理

### 2.1 数据集

- **文献汇编数据集** [`data/surfpro/surfpro_literature.csv`](../data/surfpro/surfpro_literature.csv)：1505 条记录，含 SMILES、类型、6 项性质及 DOI 引用（对应 [`data/surfpro/surfpro_bibliography.bib`](../data/surfpro/surfpro_bibliography.bib)）。
- **训练集** [`data/surfpro/surfpro_train.csv`](../data/surfpro/surfpro_train.csv)：1335 行。
- **测试集** [`data/surfpro/surfpro_test.csv`](../data/surfpro/surfpro_test.csv)：140 行。

### 2.2 目标变量可用性（缺失率）

6 个目标变量的训练样本量与缺失率差异显著，这是本项目的一个核心难点：

| 目标 | 描述 | 训练样本数 | 缺失率 |
|------|------|-----------:|-------:|
| **pCMC** | log CMC（主目标） | 1204 | 9.8% |
| **pC20** | 表面活性剂效率 | 564 | 57.8% |
| **AW_ST_CMC** | CMC 时表面张力 | 843 | 36.9% |
| **Pi_CMC** | CMC 时表面压 | 631 | 52.7% |
| **Gamma_max** | 最大表面过剩量 | 628 | 53.0% |
| **Area_min** | 最小单分子面积 | 607 | 54.5% |

> **要点**：pCMC 数据最充足（1204 条），是主战场；其余目标缺失率高达 37%~58%，属于**小样本回归**问题，对模型泛化能力提出了更高要求。

### 2.3 目标变量间相关性

- **pCMC ↔ pC20**：r = 0.76（强正相关，均为浓度类指标）
- **AW_ST_CMC ↔ Pi_CMC**：r = −0.99（几乎线性负相关，因为 Pi_CMC = γ₀ − γ_CMC）
- **Gamma_max ↔ Area_min**：r = −0.62（负相关，吸附量越大则单分子面积越小）

这些相关性既能交叉验证预测合理性，也提示**多任务建模**的潜在空间。

## 3. 特征工程：522 维 PharmHGT 风格分子特征

### 3.1 设计动机

- 传统 **ECFP/MACCS 指纹**无法充分捕获药效团与化学反应信息；
- 直接使用 **GNN** 计算开销大，且不利于树模型集成；
- 借鉴 **PharmHGT 异构图 Transformer** 思想，将多尺度分子信息编码为**扁平手工特征**，兼顾信息丰富度与计算效率。

特征提取模块：[`smiles_to_features_pharmhgt.py`](../train/train_pCMC_models/smiles_to_features_pharmhgt.py)，完整索引见 [`doc/smiles_to_features_pharmhgt_技术文档.md`](smiles_to_features_pharmhgt_技术文档.md)。

### 3.2 522 维特征构成

| 模块 | 维度 | 计算方式 | 子维度 |
|------|------|---------|--------|
| 原子级聚合特征 | 220 | 55 维原子特征 × 4 统计量（mean/std/min/max） | 55 × 4 |
| 键级聚合特征 | 56 | 14 维键特征 × 4 统计量 | 14 × 4 |
| 药效团特征 | 194 | MACCS 键指纹填充至 194 维 | 194 |
| 反应性特征 | 34 | BRICS 碎片 CRC32 分桶直方图 | 34 |
| 表面活性剂类型 | 4 | 阴/阳/非/两性离子 one-hot | 4 |
| 头基/尾链比例 | 2 | 头基原子占比、尾链碳占比 | 2 |
| 分子描述符 | 12 | 归一化 RDKit 全局描述符（MolWt、LogP、TPSA 等） | 12 |
| **总计** | **522** | | |

### 3.3 表面活性剂领域知识模块（亮点）

- **类型判定**：通过带电原子检测，区分阴离子（`[O-]/[S-]`）、阳离子（`[N+]/[n+]`）、两性离子、非离子。
- **头基检测**：SMARTS 子结构匹配（磺酸盐、硫酸酯、羧酸盐、磷酸酯、季铵、吡啶、咪唑、羟基、醚、酰胺、酯等）。
- **尾链检测**：DFS 搜索最长连续碳链（≥4 碳），标记疏水尾链。

> 这是本特征体系区别于通用分子指纹的关键——**把"两亲结构"这一领域知识显式编码进特征**。

### 3.4 缓存机制

- 特征缓存于 `data/features/surfpro/`，键为 SMILES 列 MD5 哈希；
- **缓存与目标变量绑定**（`dropna` 后有效分子不同），切换目标需重新计算；
- 每个目标 6 个特征子集均已完成预计算，训练脚本直接 `[Cache HIT]` 加载，保证 10 个模型**使用完全一致的特征**，公平对比。

## 4. 模型体系与训练流程

### 4.1 10 种模型

| 类别 | 模型 | 调参方式 |
|------|------|----------|
| 梯度提升树 | **CatBoost** | Optuna 50 轮 × 5 折 CV |
| 梯度提升树 | **LightGBM** | Optuna 50 轮 × 5 折 CV |
| 梯度提升树 | **XGBoost** | Optuna 200 轮 × 5 折 CV + Top-K holdout + gap penalty |
| 梯度提升树 | **HistGB** | Optuna 50 轮 × 5 折 CV |
| 概率梯度提升 | **NGBoost** | 固定超参（预测均值+方差） |
| 随机森林类 | **RandomForest** | Optuna 50 轮 × 5 折 CV |
| 随机森林类 | **CIF（ExtraTrees）** | Optuna 50 轮 × 5 折 CV |
| 深度前馈 | **MLP** | Optuna 50 轮 × 5 折 CV（可选） |
| 循环网络 | **RNN-LSTM** | 固定架构（3 层 LSTM，64 隐层） |
| Transformer | **Transformer Encoder** | 固定架构（3 层编码器，d_model=128） |

### 4.2 统一训练流程（5 步）

1. **特征化**：`load_or_compute_features()` 加载/计算 522 维特征并缓存；
2. **划分**：`train_test_split(0.125, random_state=42)` 划出验证集；
3. **调参**（树模型）：Optuna + K 折 CV + TPE + MedianPruner；
4. **最终训练**：在全部训练数据上用最优参数训练；
5. **输出**：时间戳运行目录（config / log / metrics / model / 图），并双写 `_runs_index.csv` 索引。

> **工程亮点**：每次运行自包含（[`runs/`](../runs/)），无需外部实验跟踪系统；训练脚本、SHAP 脚本按目标分目录组织（[`train/train_pCMC_models/`](../train/train_pCMC_models/) 等）。

### 4.3 特殊处理

- **Gamma_max 数值极小**（~10⁻⁶），训练时乘以 `y_scale=1e6` 缩放，预测 API 自动还原。
- **深度模型**把 522 维向量视为序列（reshape 为 522×1），逐特征作为时间步。

## 5. 实验结果与横向对比

> 以下数字均以 [`runs/_runs_index.csv`](../runs/_runs_index.csv)（最新索引）为准。

### 5.1 各目标最佳模型汇总

| 目标 | 最佳模型 | Test RMSE | Test R² | 第二名 |
|------|----------|----------:|--------:|--------|
| **pCMC** | **CIF（ExtraTrees）** | **0.3928** | **0.8751** | NGBoost 0.4150 / 0.8605 |
| **pC20** | **MLP** | **0.5168** | **0.8127** | CatBoost 0.6276 / 0.7237 |
| **AW_ST_CMC** | **NGBoost** | **3.9679** | **0.6924** | XGBoost 4.0139 / 0.6852 |
| **Pi_CMC** | **XGBoost** | **4.2675** | **0.6489** | CatBoost 4.3069 / 0.6424 |
| **Gamma_max** | **MLP** | — | **0.7515** | CIF 0.5956 |
| **Area_min** | **HistGB** | **0.4833** | **0.6416** | CIF 0.4859 / 0.6377 |

> **AW_ST_CMC 说明**：NGBoost 是该目标唯一采用 Optuna 重新调参的概率模型（LogScore 显著优于 CRPScore），Test R²=0.6924、RMSE=3.9679 双双第一，且输出 `Normal(mean, std)` 概率分布（avg pred std=0.4009），在给出点预测的同时提供每分子不确定性，是"精度 + 不确定性"兼备的最优选择。

### 5.2 主目标 pCMC：全模型排名

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|----------:|--------:|
| **1** | **CIF（ExtraTrees）** | **0.3928** | **0.8751** |
| 2 | NGBoost | 0.4150 | 0.8605 |
| 3 | XGBoost | 0.4199 | 0.8572 |
| 4 | CatBoost | 0.4235 | 0.8548 |
| 5 | MLP | 0.4241 | 0.8543 |
| 6 | LightGBM | 0.4311 | 0.8495 |
| 7 | HistGB | 0.4609 | 0.8280 |
| 8 | RNN-LSTM | 0.4664 | 0.8239 |
| 9 | RF | 0.4808 | 0.8128 |
| 10 | Transformer | 0.6136 | 0.6951 |

**pCMC 结论**：CIF（ExtraTrees）以 R²=0.8751、RMSE=0.3928 夺冠，且训练仅约 5 分钟（调参效率全场最高）；NGBoost 第二且能输出概率区间；前 5 名差距很小（0.39~0.42），第一梯队精度相当。

### 5.3 关键观察与共性问题

1. **小样本目标（缺失率 >50%）预测难度显著上升**：pC20、Pi_CMC、Gamma_max、Area_min 的 R² 普遍降至 0.64~0.81，远低于 pCMC 的 0.875。
2. **深度模型（RNN/Transformer）在缺失率高的目标上严重失效**：
   - AW_ST_CMC：RNN R²=−0.0514、Transformer R²=−0.0332（负值，基本无预测能力）；
   - Pi_CMC：RNN R²=−0.0315、Transformer R²=−0.0663；
   - 原因：**样本量不足 + 把特征当序列缺乏结构先验**，深度模型在小样本场景下反而不如树模型。
3. **MLP 在 pC20 上表现突出**（R²=0.8127，全场第一），说明深度前馈网络在中等样本 + 高维特征下仍有竞争力。
4. **XGBoost 拥有最复杂的调参管线**（200 轮 + Top-K holdout 泛化筛选 + 训练-验证差距惩罚），在 pCMC、AW_ST_CMC、Pi_CMC 上稳定进入第一梯队。

> 代表性可视化见各模型报告中的 `pred_vs_true.png`（预测-真值散点图 + 残差图），如 [CIF 预测图](../runs/pCMC/pCMC_cif_20260802_144459/pred_vs_true.png)。

## 6. 可解释性分析（SHAP）

### 6.1 方法

对 7 个树模型使用 **TreeExplainer** 在测试集上计算 SHAP 值，输出：
- SHAP beeswarm 图、Top-20 条形图、Top-5 依赖图、最佳/中位/最差样本瀑布图；
- 跨模型对比图：[`shap_cross_model_ranking.png`](report/pCMC/shap_cross_model_ranking.png) 与 [`shap_feature_agreement.png`](report/pCMC/shap_feature_agreement.png)。

### 6.2 核心化学结论（跨模型高度一致）

| 目标 | 主导特征 | 物理解读 |
|------|----------|----------|
| **pCMC** | **LogP、HeavyAtoms、NAtoms、MolWt** | 分子疏水性（LogP）与尺寸（原子数/分子量）决定胶束形成倾向——越疏水、越大，CMC 越低 |
| **pC20** | MolWt、LogP、maccs_77 | 疏水性 + 尺寸主导，与 pCMC 结论一致（二者本就 r=0.76 强相关） |
| **Pi_CMC** | brics_30、HBD、head_ratio、surf_cationic | 极性头基氢键能力与头尾比例调控界面吸附；**电荷类型（阳离子）影响比 pCMC 更显著** |
| **AW_ST_CMC** | 尺寸类描述符 | 与表面压/表面张力相关，见 [AW_ST_CMC 报告](report/AW_ST_CMC/AW_ST_CMC_catboost_report.md) |

**一句话总结**：*"表面活性剂的 CMC 主要由疏水性和分子尺寸决定，而界面吸附效率（Pi_CMC/表面压）额外由极性头基的氢键能力与电荷类型调控。"*

[SHAP 蜜蜂图](../runs/Pi_CMC/Pi_CMC_catboost_20260806_155128/shap_summary.png) 显示每个测试样本的 SHAP 值分布与特征取值的关系，直观展示特征对预测的正负贡献方向。

## 7. 预测服务与工程化

### 7.1 预测 API

[`use/use_models.py`](../use/use_models.py) 提供开箱即用的预测功能：

```python
from use import SmilesPredictor, SmilesPredict, list_models

# 自动选择每个目标的最优模型（按 test_rmse 最低）
SmilesPredict('CCO')                          # 默认 pCMC
SmilesPredict('CCCCCCCCCCCCCCOS(=O)(=O)[O-].[Na+]', target='pCMC')
SmilesPredict(['CCO', 'CCC(=O)O'], return_features=True)  # 批量

# 指定模型 / 其他目标
predictor = SmilesPredictor(model_name='cif', target='pCMC')
print(predictor.predict('CCO'))

# 列出所有已训练模型
list_models(target='pCMC')
```

CLI 等价：`python use/use_models.py --smiles "CCO" --target pCMC --model best`。

### 7.2 特性

- **自动选优**：从 `_runs_index.csv` 按最低 test_rmse 自动选择最佳模型；
- **多目标支持**：同一 SMILES 可预测全部 6 项性质；
- **Gamma_max 自动还原**：内部缩放对调用方透明；
- **返回特征**：可选返回 522 维特征向量，便于下游分析。

## 8. 总结与展望

### 8.1 本阶段成果

1. **完整流水线**：SMILES → 522 维特征 → 10 模型训练/调参/评估 → SHAP 解释 → 预测 API，全流程可复现。
2. **主目标 pCMC 达到 R²=0.875**（CIF/ExtraTrees），第一梯队多模型稳定在 0.85 以上，达到实用化水平。
3. **跨 6 目标系统性对比**，明确了不同模型在样本量、目标特性下的适用边界（树模型稳健、深度模型在小样本下失效）。
4. **可解释性落地**：SHAP 给出与胶体化学认知一致的结论，为"结构-性质"关系提供数据驱动证据。
5. **工程化交付**：预测 API + CLI + PDF 报告体系（每模型一份中文报告，含 md/pdf 双格式）。

### 8.2 不足与反思

- 小样本目标（pC20/Pi_CMC/Gamma_max/Area_min）精度有限（R² 0.64~0.81），数据缺失率高是主要瓶颈；
- 深度模型在 6 目标上整体不占优，序列化建模方式可能不适合扁平特征；
- 特征重要性（尤其 ExtraTrees）绝对值近零、分散，精确归因依赖 SHAP。

### 8.3 下一步计划

1. **扩充数据**：从文献/数据库补充高缺失率目标的样本（重点 pC20、Gamma_max、Area_min）。
2. **多任务学习**：利用目标间相关性（如 AW_ST_CMC↔Pi_CMC r=−0.99），尝试联合建模提升小样本目标精度。
3. **集成与不确定性**：结合 NGBoost 的概率输出构建集成模型，输出预测置信区间。
4. **特征升级**：考虑引入 GNN/分子预训练表征与现有手工特征融合，对标最新方法。
5. **Web 部署**：将预测 API 封装为可视化界面（如 Streamlit），实现"输入 SMILES 即出性质"的演示系统。
