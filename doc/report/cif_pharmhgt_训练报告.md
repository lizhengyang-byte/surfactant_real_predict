## 1. 实验概述

本实验使用 **Conditional Inference Forest（条件推断森林，CIF）** ，结合 **PharmHGT 风格 522 维分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。

**CIF 的核心特点**（区别于标准 RandomForest）：

- **统计显著性分裂**：CIF 使用**条件推断框架**（基于排列检验的统计显著性）来选择分裂变量，而非传统的 Gini 不纯度或 MSE 降低
- **无偏特征选择**：标准随机森林倾向于选择具有更多取值/水平数的特征，CIF 通过统计检验消除了这种偏好
- **内置多重检验校正**：自动处理多重比较问题，选择统计上最显著的分裂点
- **对高维特征鲁棒性更强**：特别适合 522 维这种高维输入

**底层实现**：基于 `partykit` / `ctree` 算法的 Python 封装，使用条件推断树（Conditional Inference Trees）作为基础学习器。

### 3.3 优化过程

在 50 次试验中，**最佳试验为第 48 次**，CV RMSE = **0.47693**。

**关键优化阶段**：

| Trial | CV RMSE | 关键变化 |
|:-----:|:-------:|---------|
| 0 | 0.8326 | 初始 |
| 1 | **0.5692** | `bootstrap=False` 大幅改善 |
| 5 | 0.5374 | |
| 9 | **0.5221** | `max_features=None` + `bootstrap=False` |
| 12 | 0.5152 | |
| 16 | 0.5075 | |
| 18 | **0.4931** | 首次突破 0.50 |
| 23 | 0.4948 | |
| 26 | 0.4891 | |
| 27 | **0.4785** | 接近最优 |
| **48** | **0.4769** 🏆 | **全局最佳** |

**优化过程分析**：

1. **`bootstrap=False` 是关键发现**（Trial 1）：不使用自助采样（即使用全部样本训练每棵树）比使用 bootstrap 好得多。这与标准随机森林（`bootstrap=True`）不同，可能是因为 CIF 的统计检验机制已经提供了足够的正则化

2. **`max_features=None`**：使用全部 522 个特征进行分裂，与 RandomForest 的最佳设置一致

3. **`min_samples_leaf=1`**：允许叶节点只有 1 个样本，树几乎不限制生长深度

4. **CV RMSE=0.4769**：CIF 的 CV 表现（0.4769）优于标准 RandomForest（0.5200）约 **8.3%**，也优于 LightGBM（0.4818）和 XGBoost（0.4916）

5. **大量试验被修剪**（50 次中约一半被修剪），因为 CIF 的统计检验机制在较差参数组合下会快速失效

### 3.4 最佳超参数与 RandomForest 对比

| 超参数 | CIF（最佳） | RandomForest（最佳） | 差异 |
|--------|:----------:|:-------------------:|:----:|
| `n_estimators` | **1,161** | 633 | CIF 需要更多树 |
| `max_depth` | **21** | 24 | 相近 |
| `min_samples_split` | **7** | 3 | CIF 更保守 |
| `min_samples_leaf` | **1** | 2 | CIF 允许单样本叶节点 |
| `max_features` | **None** | None | 一致 |
| `bootstrap` | **False** 🔑 | True | **关键差异** |
