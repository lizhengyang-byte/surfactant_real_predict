## 概述

RNN（LSTM）将 522 维特征向量**重塑为序列** `(batch, 522, 1)`——把每个特征维度当作一个时间步，用 3 层 LSTM 逐维读取并聚合信息，最后以末隐状态映射到单值输出。这一"把特征当序列"的设计是深度模型路线的另一种尝试，但特征维度间本无时间先后语义，序列化仅是工程上的权宜。

在 Area_min 任务中，RNN 的 Test R² = 0.2037、Test RMSE = 0.7203，**在 9 个模型中排名第 9（垫底）**，是全模型唯一 R² 低于 0.3 的模型。Area_min 描述表面活性剂分子在气-液界面单分子膜中的最小截面积（nm²），与 Gamma_max 负相关（r = −0.62）。RNN 的失败与其余深度模型（MLP 0.53）形成对比，说明序列式建模在该 target 上不适用。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练池 607 条（531 训练 + 76 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **序列化**：522 维输入重塑为 `(batch, 522, 1)`，每维作为一个时间步。

## 超参数与调优

RNN 使用**固定架构，无 Optuna 调参**（区别于 MLP）：

| 参数 | 值 |
|------|-----|
| 层数 | 3 层 LSTM |
| hidden | 64 |
| learning_rate | 1e-3 |
| weight_decay | 1e-5 |
| batch_size | 32 |

该配置为本项目既定模板（3 层 LSTM、64 隐单元），未针对 Area_min 重新搜索。从结果看，64 隐单元对 522 维"序列"的信息容量偏小，且无任何正则调节手段。

## 训练过程

最终模型在 531 条数据上训练，**早停在 epoch 415 触发**（验证最优 RMSE = 0.6212 出现在 epoch 200）。训练曲线显示验证 RMSE 波动剧烈（epoch 50 的 0.79 → epoch 200 的 0.62 → epoch 250 回升至 0.75），自 epoch 200 后验证误差不再改善，训练进入无效震荡；早停机制在 415 轮止损，最终以 epoch 200 的验证最优权重交付。

> 说明：本次 RNN 运行**未生成** pred_vs_true 预测-真值散点图与 SHAP 图（深度模型训练脚本不输出绘图文件）。如需可视化，可复用 `train_rnn_use_pharmhgt_features.py` 中加载的缓存特征另行绘制。

## 测试结果

| 指标 | 值 |
|------|-----|
| Test RMSE | **0.7203** |
| Test MAE | **0.4872** |
| Test R² | **0.2037** |
| Best val RMSE | 0.6212 |

Test RMSE（0.7203）较 Best val（0.6212）进一步恶化约 0.10，且 **MAE（0.4872）为 9 个模型中最高**、R²（0.2037）为全模型唯一低于 0.3 者。Test MSE = 0.5189 与之印证。该模型仅能解释测试方差的两成，基本不具备 Area_min 的预测能力。

## 特征重要性

RNN 为黑盒序列模型，日志未输出特征重要性。其将 522 维特征逐维按序列读取，LSTM 的隐状态在时间步间压缩信息，缺乏明确的归因结构；若需解释，只能借助逐特征扰动或 SHAP 的近似 KernelExplainer 事后估计（本次未生成）。基于其余 7 个树模型的共识结论，可推断 Area_min 主要由 MolWt、MACCS 子结构位、头尾结构等特征驱动——但 RNN 的精度已不足以支撑对该结论的进一步佐证。

## 结论与评价

**优点：**
- 训练速度快（约 2 分钟），早停机制在验证震荡中正确止损，未无限消耗算力。
- 作为深度模型基线，验证了"序列式建模 + 522 维手工特征"路线在该 target 上的不适用性，为后续方法选择提供了反面证据。

**不足：**
- **9 个模型中垫底（R² = 0.2037）**，MAE 全模型最高（0.4872），预测基本失效。
- 固定架构无调参、64 隐单元容量不足；"把特征当序列"的假设缺乏物理依据，特征维度间并无时间语义。
- 训练震荡剧烈（val RMSE 0.62~0.79 大幅波动），收敛不稳定，复现性差。

**横向定位（9 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 7 | XGBoost | 0.5495 | 0.5366 |
| 8 | MLP | 0.5547 | 0.5278 |
| **9** | **RNN** | **0.7203** | **0.2037** |

RNN 与 MLP 的对比极具说明性：同为深度模型，**前馈 MLP（0.53）远超序列式 RNN（0.20）**——522 维特征更适合整体非线性组合（MLP）而非时序压缩（RNN）。在 Area_min 这一小样本（531）+ 高维（522）任务上，深度模型整体弱于树模型，RNN 尤其不建议选用；交付应优先 HistGB/CIF。
