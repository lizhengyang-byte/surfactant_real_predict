## 概述

MLP（多层感知机）是 10 个模型中唯一的**前馈全连接深度网络**（RNN/Transformer 为序列式深度模型）。架构为 `Linear → BatchNorm → GELU → Dropout` 重复堆叠 N 层，末层映射到单值输出，以 522 维特征向量整体作为输入（不做序列化）。深度网络对特征的**非线性组合与隐式高阶交互**建模能力强于树模型，是"手工特征 + 神经网络"路线的代表。

在 pCMC 任务中，MLP 的 Test R² = 0.8543、Test RMSE = 0.4241，排名第 5，是**深度模型中的最优者**（显著优于 RNN 与 Transformer），整体性能与 CatBoost 几乎持平。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载，与其余模型一致。
- **数据规模**：训练集 1204 条（1053 训练 + 151 验证），测试集 140 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。

## 超参数与调优

采用 **Optuna 50 轮 × 5 折交叉验证**（TPE 采样器 + MedianPruner）。这是深度模型中唯一使用 Optuna 的（RNN/Transformer 用固定架构）。

**最优试验（Trial 42，CV RMSE = 0.4313）：**

| 参数 | 值 |
|------|-----|
| n_layers | 3 |
| hidden_dim | 990 |
| dropout | 0.267 |
| activation | **gelu** |
| learning_rate | 0.00673 |
| weight_decay | 1.06e-4 |
| batch_size | 95 |
| Best CV RMSE | 0.4313 |

**调优过程观察：**
- 早期试验（Trial 0/1）表现极差（CV RMSE 0.84 / 1.67），原因是学习率过低（1.5e-5 / 3.5e-5）导致欠拟合；**搜索快速收敛到 lr ∈ [0.002, 0.01] 的合理区间**。
- 最优解显著偏好 **GELU 激活 + 中等隐藏层（700~990）+ 3~6 层**的结构，dropout 稳定在 0.13~0.33 的适度区间以平衡过拟合。
- Trial 37 与 Trial 42 的 CV RMSE 仅差 2e-5（0.431314 vs 0.431294），说明搜索已收敛、对超参不敏感，**最优解稳定**。
- 50 轮中 9 轮被剪枝；单轮 5 折 CV 平均耗时约 1.7 分钟，深度网络的调参成本（约 90 分钟）显著高于树模型（LightGBM 仅 3 分钟）。

## 训练过程

最终模型以最优参数在 1053 条数据上训练，**早停在 epoch 265** 触发（验证集 RMSE = 0.4480）。训练约 265 个 epoch 表明网络需要较多迭代才能收敛，但由于早停机制，未出现过拟合蔓延；最终以验证最优权重（而非末轮权重）作为交付模型。

> 说明：最终训练与调参在同一脚本中连续执行（调参日志末尾包含最终训练段），`pCMC_mlp_tuning` 目录即本次调参过程存档。

## 特征重要性

MLP 为黑盒网络，日志未输出特征重要性。其输入为 522 维原始特征向量，重要特征需借助 **SHAP 的 KernelExplainer** 事后归因（`shap_mlp.py` 路径下可生成，但本次 pCMC 运行未生成 SHAP 图）。基于其余模型的一致性结论，可推断其预测主要由 LogP、HeavyAtoms、MolWt 等全局疏水性/尺寸描述符驱动。

## 结论与评价

**优点：**
- **深度模型中的最优者**：R² = 0.8543，与 CatBoost 持平，证明神经网络能有效挖掘 522 维手工特征的非线性结构。
- 使用 Optuna 充分调参（vs 固定架构的 RNN/Transformer），超参选择有依据、结果可复现。
- 早停 + Dropout + weight_decay 三重正则，泛化稳健。

**不足：**
- 调参成本高（约 90 分钟），为树模型的数十倍。
- 黑盒模型，可解释性差；MAE（0.3163）在 10 个模型中偏高，说明对中间区间分子存在系统性偏差。
- 不提供不确定性估计（对比 NGBoost）。
