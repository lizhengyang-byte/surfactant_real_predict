# MLP + PharmHGT 特征 表面活性剂 pCMC 预测 — 训练报告

> **报告生成日期**: 2026-07-23  
> **运行时间戳**: 2026-07-23 17:35:09（第二轮，Optuna 调参版）  
> **模型**: MLP（多层感知机，3 层全连接网络）  
> **特征**: PharmHGT 风格 522 维分子特征  
> **目标变量**: pCMC (log CMC，临界胶束浓度对数值)  
> **硬件**: CUDA (GPU)

## 1. 实验概述

本实验使用 **MLP（多层感知机）** 深度前馈神经网络，结合 **PharmHGT 风格 522 维手工分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。**与第一版固定参数不同，本版本引入了 Optuna 超参数优化**，取得了项目最佳测试性能。

实验流程包括：

1. 特征提取（从 SMILES 计算 522 维特征，缓存命中）
2. 训练/验证集划分（1,053 训练 + 151 验证）
3. **Optuna 超参数优化（50 次试验 × 5 折交叉验证）**
4. 最终模型训练（全量训练数据 + 早停）
5. 测试集评估（140 个样本）
6. 模型保存

## 3. 模型架构

### 3.1 网络结构

```
输入 (522)
    ↓
Linear(522 → 990) + BatchNorm1d + GELU + Dropout(0.267)
    ↓
Linear(990 → 990) + BatchNorm1d + GELU + Dropout(0.267)
    ↓
Linear(990 → 990) + BatchNorm1d + GELU + Dropout(0.267)
    ↓
Linear(990 → 1) → 输出 (pCMC 预测值)
```

### 3.2 模型参数

| 参数 | 值 |
|------|-----|
| 输入维度 | 522 |
| 隐藏层数 | **3** 层（Optuna 确定） |
| 隐藏层维度 | **990**（Optuna 确定） |
| 激活函数 | **GELU**（高斯误差线性单元） |
| 归一化 | 每层后接 **BatchNorm1d** |
| 正则化 | 每层后接 **Dropout(0.267)**（Optuna 确定） |
| **总参数量** | **~2.98M**（约 298 万参数） |

### 3.3 训练配置

| 配置项 | 值 |
|--------|-----|
| 优化器 | **AdamW** |
| 学习率 | **0.00673**（Optuna 确定） |
| 权重衰减 | **1.06e-4**（Optuna 确定） |
| 批次大小 | **95**（Optuna 确定） |
| 最大轮数 | 3,000（实际训练至 **795 轮早停**） |
| 早停轮数 | 50 |
| 验证评估频率 | 每 5 个 epoch |
| 学习率调度 | 无（固定学习率） |

### 3.4 架构设计要点

1. **宽度优先**：隐藏层维度 990 几乎达到输入维度 522 的两倍，提供了充足的表征容量
2. **3 层深度**：相比第一版的 4 层减少 1 层，Optuna 搜索发现 3 层在 522→1 的映射任务中表现更优
3. **更高 Dropout（0.267）**：相比于第一版的 0.1，Optuna 选择了更强的正则化，有效控制了 ~2.98M 参数量在大约 1,053 训练样本上的过拟合风险
4. **较大的学习率（0.00673）**：高于第一版的 0.001，配合较大的 batch size（95）实现了更快的收敛

## 4. 训练过程

### 4.1 超参数优化 (Optuna)

MLP 在第一版使用固定参数，本版本引入了 Optuna 超参数搜索：

| 配置项 | 值 |
|--------|-----|
| 优化框架 | Optuna |
| 采样器 | TPE (Tree-structured Parzen Estimator) |
| 试验次数 | **50** |
| 交叉验证折数 | 5 |
| 修剪器 | MedianPruner |
| 目标函数 | CV RMSE（最小化） |

**搜索空间与最佳值**：

| 超参数 | 搜索范围 | **最佳值** |
|--------|---------|-----------|
| `n_layers` | [2, 6] | **3** |
| `hidden_dim` | [256, 1024] | **990** |
| `dropout` | [0.0, 0.5] | **0.267** |
| `activation` | ['relu', 'gelu', 'silu'] | **gelu** |
| `lr` | [1e-4, 1e-2] (log) | **0.00673** |
| `weight_decay` | [1e-6, 1e-3] (log) | **1.06e-4** |
| `batch_size` | [16, 128] | **95** |

在 50 次试验中，**最佳试验为第 42 次**，CV RMSE = **0.4313**。

**优化过程**：
- 最佳值 0.4313 在第 42 次试验中找到，后续试验未能超越
- 最佳 `activation` 为 `gelu`，与第一版一致，验证了 GELU 在分子特征回归任务中的稳定性
- 最佳 `n_layers=3`，说明对于 522→1 的映射任务，3 层网络已足够，更深（4-6 层）反而可能过拟合
- 最佳 `dropout=0.267` 和 `weight_decay=1.06e-4` 的结合提供了有效的正则化

### 4.2 最终模型训练

| 配置项 | 值 |
|--------|-----|
| 训练数据 | 全量 1,204 条 |
| 最大轮数 | 3,000 |
| 早停轮数 | 50 |
| 最佳验证 RMSE | **0.1269** |

**收敛过程**：

| Epoch | Val RMSE | 最佳 Val RMSE |
|-------|---------|--------------|
| 300 | 0.2083 | **0.1756** |
| 600 | 0.2003 | **0.1308** |
| **795** | — | **0.1269** 🏆（早停触发） |

**收敛特征**：
- 使用 Optuna 确定的最佳超参数后，验证 RMSE 从 300 轮时的 0.1756 下降至 600 轮的 0.1308，最终在第 795 轮达到最佳 0.1269
- 795 轮触发早停（50 轮未改善），比第一版（2,270 轮）大幅缩短，表明 Optuna 调参使得学习更高效
- 最佳验证 RMSE **0.1269** 较第一版（0.0557）**偏高**，但测试 R²（0.9052 vs 0.8679）**大幅提升**，说明 Optuna 调参有效平衡了验证集拟合与测试集泛化
