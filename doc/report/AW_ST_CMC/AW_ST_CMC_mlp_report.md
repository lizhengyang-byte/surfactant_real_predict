## 概述

MLP（多层感知机）是 10 个模型中唯一的**前馈全连接深度网络**（RNN/Transformer 为序列式深度模型）。架构为 `Linear → BatchNorm → GELU → Dropout` 重复堆叠 N 层，末层映射到单值输出，以 522 维特征向量整体作为输入（不做序列化）。深度网络对特征的**非线性组合与隐式高阶交互**建模能力强于树模型，是"手工特征 + 神经网络"路线的代表。

在 AW_ST_CMC 任务中，MLP 的 Test R² = 0.6348、Test RMSE = 4.3235，排名第 4，是**深度模型中的最优者**（显著优于 RNN/Transformer 的负 R²），并超越了 HistGB、LightGBM 等部分树模型。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载，与其余模型一致。
- **数据规模**：训练集 843 条（737 训练 + 106 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。

## 超参数与调优

采用 **Optuna 50 轮 × 5 折交叉验证**（TPE 采样器 + MedianPruner），搜索空间覆盖 n_layers[2,6]、hidden_dim[128,1024]、dropout、activation、learning_rate、weight_decay、batch_size。这是深度模型中唯一使用 Optuna 的（RNN/Transformer 用固定架构）。

**最优试验（Trial 7，CV RMSE = 3.6940）：**

| 参数 | 值 |
|------|-----|
| n_layers | 3 |
| hidden_dim | 379 |
| dropout | 0.2713 |
| activation | **gelu** |
| learning_rate | 0.00913 |
| weight_decay | 7.26e-5 |
| batch_size | 38 |
| Best CV RMSE | 3.6940 |

**调优过程观察：**
- 早期试验（Trial 0/1）表现极差（CV 22.1 / 34.3），原因是学习率过低（1.5e-5 / 3.5e-5）导致欠拟合；**Trial 2 起学习率进入 [2e-4, 9e-3] 区间后迅速收敛到 3.7~3.9**。
- **Trial 7 以 3.6940 锁定最优并保持到 50 轮结束**，后续 42 轮（含 Trial 25 的 3.6946、Trial 26 的 3.6945）均未突破，说明搜索已收敛、最优解稳定。
- 最优解偏好 **GELU 激活 + 3 层 + 中等隐藏层（379）**；激活函数从早期 relu/leaky_relu 逐渐被 gelu 取代，gelu 成为优势激活。
- 50 轮中 32 轮完成、18 轮被剪枝；单轮 5 折 CV 平均耗时约 3.5 分钟，深度网络调参成本（约 100 分钟）显著高于树模型（LightGBM 仅 5 分钟）。

## 训练过程

最终模型以最优参数在 737 条数据上训练，**早停在 epoch 205** 触发，验证集 RMSE 最优值 **3.5588**（比调参 CV 的 3.6940 更好）。训练 205 个 epoch 表明网络需要较多迭代才能收敛，但早停机制避免了过拟合蔓延；最终以验证最优权重交付。

> 说明：最终训练与调参在同一脚本中连续执行（调参日志末尾包含最终训练段），`AW_ST_CMC_mlp_tuning` 目录即本次调参过程存档。

> 说明：本次 MLP 运行**未生成** pred_vs_true 预测-真值散点图与 SHAP 图（该训练脚本未输出绘图文件）。如需可视化，可复用 `train_mlp_use_pharmhgt_features.py` 中加载的缓存特征另行绘制。

Test RMSE（4.3235）高于验证集最优（3.5588），Test MSE = 18.6930，说明在独立测试集（70 条）上误差有所回升。R² = 0.6348 排名第 4，虽逊于第一梯队（≈0.68），但**明显优于 RNN（−0.05）与 Transformer（−0.03）**，验证了 MLP 作为深度模型中唯一有效者的地位。

## 特征重要性

MLP 为黑盒网络，日志未输出特征重要性。其输入为 522 维原始特征向量，重要特征需借助 **SHAP 的 KernelExplainer** 事后归因。基于其余模型的一致性结论，可推断其预测主要由原子聚合统计（atom_std_44 等）、阳离子类型 surf_cationic 与分子量/疏水描述符驱动——这些特征在 7 个树模型的 SHAP 与重要度排序中反复位居前列，是 AW_ST_CMC 的稳健归因。

## 结论与评价

**优点：**
- **深度模型中的最优者**：R² = 0.6348，超越 HistGB/LightGBM 等部分树模型，证明神经网络能有效挖掘 522 维手工特征的非线性结构。
- 使用 Optuna 充分调参（vs 固定架构的 RNN/Transformer），超参选择有依据、结果可复现。
- 早停 + Dropout + weight_decay 三重正则，验证集 RMSE（3.5588）优于 CV，泛化良好。

**不足：**
- 调参成本高（约 100 分钟），为树模型的数十倍。
- 黑盒模型，可解释性差；Test−val 差距（4.32 vs 3.56）表明独立测试集上存在误差回升。
- 不提供不确定性估计（对比 NGBoost）。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 2 | XGBoost | 4.0139 | 0.6852 |
| 3 | CatBoost | 4.0407 | 0.6810 |
| **4** | **MLP** | **4.3235** | **0.6348** |
| 5 | HistGB | 4.4287 | 0.6168 |
| 6 | LightGBM | 4.5686 | 0.5922 |

MLP 以 0.28~0.31 的 RMSE 差距位列第一梯队之后、第二梯队之前。作为深度网络代表，其**扩展潜力**（更深的架构、特征自学习）优于树模型；在现有手工特征 + 小样本（737）配置下，精度逊于 NGBoost/XGBoost/CatBoost，但已是深度路线在该 target 上的最佳选择。
