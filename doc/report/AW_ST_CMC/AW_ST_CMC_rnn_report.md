## 概述

RNN-LSTM 是 10 个模型中的**序列式深度模型**之一（与 Transformer 同类，与 MLP 的前馈路线相对）。本项目将 522 维特征向量 reshape 为 (batch, 522, 1)，**把每个特征维度当作一个时间步**，用 3 层 LSTM（64 隐藏单元）逐维扫描特征序列，隐状态经线性层映射到单值输出。架构为**固定配置，未做 Optuna 调参**。

在 AW_ST_CMC 任务中，RNN 的 Test R² = **−0.0514**、Test RMSE = 7.3354，**排名第 10（垫底）**。其 R² 为负，意味着预测**不如"直接用均值"这一朴素基线**，模型在该 target 上完全失效——这是本任务中两个（RNN/Transformer）**完全失效的深度模型**之一，值得重点分析。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练集 843 条（737 训练 + 106 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **序列化方式**：522 维特征 → (batch, 522, 1)，每特征维度为一步长。

## 超参数与调优

采用 **固定架构**（深度模型中仅 MLP 使用 Optuna，RNN/Transformer 均不调参）：

| 参数 | 值 |
|------|-----|
| n_layers（LSTM 层数） | 3 |
| hidden_dim | 64 |
| dropout | 0.2 |
| activation | relu |
| learning_rate | 1e-3 |
| weight_decay | 1e-5 |
| batch_size | 32 |
| 最大 epoch | 800（早停保护） |

**设计说明：** 3 层 LSTM、64 隐藏单元是轻量序列结构，lr=1e-3 + weight_decay=1e-5 为保守训练配置。与 MLP 相比，RNN 缺少 Optuna 调参、且 64 维隐状态承载的信息量远小于 MLP 的 379 维全连接层，模型容量明显偏小。

## 训练过程

- 固定架构直接训练：Val RMSE 在 epoch 50 即达 6.9954，随后缓慢收敛至 **epoch 100 起稳定在 6.99**（best val RMSE = **6.9906**，epoch 200 取得）。
- **早停在 epoch 320 触发**——但值得注意的是，验证误差从 epoch 100 到 300 几乎不再改善（6.9906 ~ 6.9948 之间震荡），说明网络**很快陷入平台期，验证集上几乎无学习收益**。

> 说明：本模型训练脚本未生成 pred_vs_true 与 SHAP 图（深度模型统一不输出绘图文件）。

## 测试结果

| 指标 | 值 |
|------|-----|
| Test RMSE | **7.3354** |
| Test MAE | **5.7533** |
| Test R² | **−0.0514** |
| Best val RMSE | 6.9906 |

Test MSE = 53.8085，RMSE（7.33）甚至**高于验证最优（6.99）**，R² 为负。对照测试集 AW_ST_CMC 的数值量级（表面张力典型区间约 25~50 mN/m），7.3 的 RMSE 意味着预测误差与目标本身标准差相当，模型未能学到任何有效结构——**预测与随机猜测无异，甚至劣于常数预测**。

## 特征重要性

RNN 为黑盒序列网络，日志未输出特征重要性；且本任务 R² 为负，**模型未学到有效规律，任何特征归因都缺乏意义**。仅能推断：将 522 维无序手工特征当作"时间序列"扫描的假设不成立——这些特征维度之间没有可被 LSTM 利用的时序依赖，反而破坏了 MLP 中"整体向量并行处理"的交互建模能力。

## 结论与评价

**优点：**
- 训练快速（约 2 分钟）、配置简单、无调参负担。

**不足：**
- **完全失效**：Test R² = −0.0514（第 10 名），劣于常数基线，无实用价值。
- 验证集 RMSE 从 epoch 100 起平台化（~6.99），早停无法挽救——不是训练不充分，而是**模型结构/序列化假设与任务不匹配**。
- 64 隐藏单元的 LSTM 容量过小，且把 522 维特征当序列处理缺乏物理依据。

**关于失效原因的分析：** AW_ST_CMC 与其他 target 一样，522 维特征是无序的手工描述符，**不具备序列/时序语义**。LSTM 逐维扫描引入的"顺序"是人为强加的噪声；同时，训练样本仅 737 条，远不足以支撑序列模型的海量参数。相比之下，MLP（同样 522 维输入、不做序列化、容量更大、经 Optuna 调参）R² = 0.6348，而 RNN 为负——**差距根源在序列化建模方式，而非"深度"本身**。这也是本项目将深度路线收敛到"手工特征 + MLP"、而把 RNN/Transformer 标记为失效模型的直接证据。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 8 | RandomForest | 4.7340 | 0.5621 |
| 9 | Transformer | 7.2719 | -0.0332 |
| **10** | **RNN** | **7.3354** | **-0.0514** |

RNN 与 Transformer 构成唯一的"负 R²"梯队，双双垫底。两者在 AW_ST_CMC 上均为无效模型，**不应作为该 target 的预测工具**；追求精度应使用第一梯队（NGBoost/XGBoost/CatBoost），追求深度路线应使用 MLP。
