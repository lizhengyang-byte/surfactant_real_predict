# Transformer 模型报告 — AW_ST_CMC 预测

## 报告信息

| 项目 | 内容 |
|------|------|
| 目标变量 | AW_ST_CMC（表面活性剂在 CMC 时的表面张力，单位 mN/m） |
| 运行目录 | `runs\AW_ST_CMC\AW_ST_CMC_transformer_20260805_151238` |
| 运行时间 | 15:12 开始 ~ 15:23 结束（约 11 分钟） |

| 报告生成日期 | 2026-08-07 |

## 概述

Transformer 是 10 个模型中的**序列式深度模型**之一（与 RNN 同类）。本项目将 522 维特征向量 reshape 为 (batch, 522, 1)，**把每个特征维度当作一个时间步**，用 3 层 Transformer Encoder（d_model=128、4 头注意力、FFN=256、GELU）对特征序列做自注意力建模，配合 CosineAnnealingLR 学习率调度与梯度裁剪（grad_clip=5.0）。架构为**固定配置，未做 Optuna 调参**。

在 AW_ST_CMC 任务中，Transformer 的 Test R² = **−0.0332**、Test RMSE = 7.2719，排名第 9（倒数第二）。其 R² 为负，意味着预测**不如"直接用均值"这一朴素基线**，模型在该 target 上完全失效——与 RNN 一同构成本项目两个完全失效的深度模型，值得重点分析。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练集 843 条（737 训练 + 106 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **序列化方式**：522 维特征 → (batch, 522, 1)，每特征维度为一步长。

## 超参数与调优

采用 **固定架构**（深度模型中仅 MLP 使用 Optuna，RNN/Transformer 均不调参）：

| 参数 | 值 |
|------|-----|
| d_model | 128 |
| num_layers（编码器层数） | 3 |
| nhead（注意力头数） | 4 |
| dim_feedforward（FFN） | 256 |
| activation | gelu |
| dropout | 0.1 |
| learning_rate | 1e-3 |
| weight_decay | 1e-5 |
| batch_size | 16 |
| 最大 epoch | 500（早停保护） |
| 调度/裁剪 | CosineAnnealingLR、grad_clip=5.0 |

**设计说明：** 4 头注意力 × d_model=128 是轻量 Transformer，FFN 256 居中。与 MLP 相比，Transformer 缺少 Optuna 调参、且自注意力机制对 522 维"伪序列"的建模假设存疑。

## 训练过程

- 固定架构直接训练：Val RMSE 在 epoch 15 达到最优 **6.9977**，此后至 epoch 105 在 7.00~7.26 之间小幅震荡。
- **Epoch 110 起验证误差断崖式爆增至 45.5+** 并持续（45.5 ~ 46.0），呈现明显的**训练发散/崩溃**（自注意力在 737 样本上进入不稳定状态），早停在 epoch 165 触发。

> 说明：本模型训练脚本未生成 pred_vs_true 与 SHAP 图（深度模型统一不输出绘图文件）。

## 测试结果

| 指标 | 值 |
|------|-----|
| Test RMSE | **7.2719** |
| Test MAE | **5.7139** |
| Test R² | **−0.0332** |
| Best val RMSE | 6.9977 |

Test MSE = 52.8808，RMSE（7.27）高于验证最优（6.9977），R² 为负。与 RNN 一样，7.3 的 RMSE 与 AW_ST_CMC 目标本身的标准差同量级，**预测未学到有效结构**。与 RNN 的"平台期失效"相比，Transformer 是"中期崩溃"——即便早停保留了 epoch 15 的权重，测试表现依旧为负。

## 特征重要性

Transformer 为黑盒注意力网络，日志未输出特征重要性；且本任务 R² 为负、训练中期还发生发散，**任何特征归因都缺乏意义**。仅能推断：把无序手工特征当作序列让自注意力去捕捉"跨维度关系"的建模假设不成立——特征维度之间本无时序依赖，且 522 长序列对 737 样本的自注意力训练极不稳定。

## 结论与评价

**优点：**
- 架构现代、代码可复现；grad_clip 与早停成功防止了发散彻底污染交付权重。

**不足：**
- **完全失效**：Test R² = −0.0332（第 9 名），劣于常数基线，无实用价值。
- **Epoch 110 起验证损失爆增至 45+**，训练不稳定，早停前的权重已无意义。
- 自注意力在 522 维伪序列 + 737 样本上的组合既不高效也不稳定，固定架构又无调参兜底。

**关于失效原因的分析：** AW_ST_CMC 的 522 维特征是无序的手工描述符，**不具备序列/时序语义**。Transformer 的自注意力需要在足够大的数据上学习跨 token 关联，而 737 样本对"522 长度序列"的训练极不稳定（本次甚至中期发散）。对比鲜明的是：**MLP（同样 522 维输入、不做序列化、经 Optuna 调参）R² = 0.6348**，而 RNN/Transformer 双双为负——**差距根源在序列化建模方式与样本量不匹配，而非"深度"本身**。这也印证了本项目深度路线的正确收敛方向是"手工特征 + MLP"，而非序列式模型。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 7 | CIF (ExtraTrees) | 4.6913 | 0.5700 |
| 8 | RandomForest | 4.7340 | 0.5621 |
| **9** | **Transformer** | **7.2719** | **-0.0332** |
| 10 | RNN | 7.3354 | -0.0514 |

Transformer 与 RNN 构成唯一的"负 R²"梯队，双双垫底。两者在 AW_ST_CMC 上均为无效模型，**不应作为该 target 的预测工具**；追求精度应使用第一梯队（NGBoost/XGBoost/CatBoost），追求深度路线应使用 MLP。
