## 概述

RNN 使用 **3 层 LSTM** 处理 522 维特征向量。本项目对深度序列模型有一个特殊设计：**将 522 维特征向量重塑为 `(batch, 522, 1)`，即把每个特征维度当作一个时间步、逐维送入 LSTM**（`Deep models treat 522-dim vector as sequence`）。LSTM 因此沿"特征轴"顺序读取 522 个时间步，最终隐藏状态经线性层映射为 Gamma_max。

这一设计的前提是**特征维度之间存在可被顺序建模的"序列依赖"**。但 522 维 PharmHGT 特征由原子聚合、键聚合、MACCS、BRICS、头尾比、描述符等**异构模块拼接**而成，维度间并无自然的时序关系——这是 RNN 在本任务中偏弱的结构性原因。

在 Gamma_max 任务中，RNN 的 Test R² = **−0.01**，在 10 个模型中排名**最末（第 10）**，且是唯一 R² 接近零（等价于预测均值）的模型——对最大表面超量**完全失效**。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练池 628 条（**549 训练 + 79 验证**），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **训练缩放**：训练脚本对 y 乘以 `Y_SCALE = 1e6`（config.json `"y_scale": 1000000`），验证与测试评估均为缩放单位。

## 特征重要性

LSTM 为黑盒循环网络，日志无特征重要性输出。其"逐维读入"的机制使每个特征维度等价地参与时序传播，**无法区分特征主次**。鉴于模型在本任务上未学到有效结构（R²≈0），任何特征级解释都失去意义。可推断其失败根源在于：522 维异构特征**无自然时序关系**，LSTM 的序列假设与特征结构不匹配，且 549 条小样本不足以让循环网络克服这一结构性障碍。

## 结论与评价

**优点：**

- 训练仅 1.5 分钟，成本低。

**不足：**
- **完全失效**：Test R² = −0.01，排名垫底，是唯一等价于预测均值的模型；与 pCMC 任务（R² 0.8239）相比断崖式下跌。
- 验证 RMSE 全程平线，训练无收敛，早停无济于事。

## 附录（专题说明）：Test R² = −0.01 成因详析

本附录基于 `runs\Gamma_max\Gamma_max_rnn_20260805_202604\model.pkl` 与缓存的测试特征（`data\features\surfpro\Gamma_max\`）独立复算，逐层解释「R² 为何恰好是 −0.01」。

### 1. 结论先行

**R² = −0.01 不是计算错误，而是可精确复现的数学事实**：该 LSTM 在训练后**退化为"对所有输入输出近似同一常量"的预测器**（输出 2.3342×10⁻⁶ mol/m²），且这个常量恰好偏离测试集均值约 1.4×10⁻⁷，使其平方残差略大于"直接预测测试均值"的基线，因此 R² 落在 0 下方约 1% 处。R² 为负的含义是：**模型连"永远预测均值"的地线都不如一点点**。

### 2. 公式与实测数值

R² = 1 − SS_res / SS_tot，其中 SS_res 为模型残差平方和，SS_tot 为测试集围绕其均值的总平方和。用本运行保存的模型在 70 个测试样本上复算（原始单位 mol/m²）：

| 量 | 实测值 |
|---|---|
| SS_tot = Σ(y_true − ȳ_test)² | 1.3890×10⁻¹⁰ |
| SS_res = Σ(y_true − ŷ)² | 1.4030×10⁻¹⁰ |
| **R² = 1 − 1.4030/1.3890** | **−0.010008 → round4 = −0.01** |
| Test RMSE / MAE（原始） | 1.4157×10⁻⁶ / 1.0487×10⁻⁶ → round4 = 0.0000 |

RMSE/MAE 的 0.0000 是 4 位小数舍入假象（量级 ~10⁻⁶），R² 无量纲不受影响，是唯一可信指标。**记录值 −0.01 与独立复算完全一致**（metrics.json、日志、索引三处均为 round4 结果）。

### 3. 为什么是"微负"而不是"更负"：常量预测器的几何

R² 的分母 SS_tot 以**测试集自身均值**为参照。若模型输出恒等于测试均值（c = ȳ_test），则 SS_res = SS_tot，R² 恰为 0——这是"预测均值"基线。任何常量 c ≠ ȳ_test，R² 即小于 0；偏离越大越负。

实测该模型的预测行为（70 个测试样本）：

| 量 | 值 |
|---|---|
| 预测均值 c（原始单位） | 2.3342×10⁻⁶ |
| 预测标准差 | 7.78×10⁻¹¹（信号标准差 1.41×10⁻⁶ 的 **0.005%**） |
| 测试集均值 ȳ_test | 2.1930×10⁻⁶ |
| c 与测试均值偏差 | +1.412×10⁻⁷ |

对照不同常量的 R²：

| 假设预测方式 | R² |
|---|---|
| 常量 = 测试均值 | 0.000000（地线） |
| 常量 = 训练均值（2.2720×10⁻⁶） | −0.003139 |
| 常量 = 模型实际输出 c（2.3342×10⁻⁶） | **−0.010046** |
| 模型实际预测 | **−0.010008**（逐样本微小波动仅贡献 0.00004） |

可见 R² ≈ −0.01 就是"把所有测试样本都预测为 2.3342×10⁻⁶"这个常量策略的闭合表达式——比预测测试均值差约 1%，数值上完全自洽。

### 4. 三重实证：模型从训练起点就未学到任何结构（非过拟合）

| 集合 | 模型预测标准差 | 目标标准差 | 压缩比 | 结论 |
|---|---|---|---|---|
| 测试集 | 7.78×10⁻¹¹（原始） | 1.41×10⁻⁶ | ~1.8 万倍 | 输出恒为常量 |
| 训练集 | 9.9×10⁻⁵（缩放） | 1.55（缩放） | ~1.6 万倍 | **非过拟合**（训练时同样退化，不是"训练学好、测试失效"） |
| 验证集 | 模型 val RMSE = **2.13**（缩放） | 常量预测地板 = **2.128**（= val 目标 std） | 重合到 2 位小数 | 与日志"全程平线 2.13"吻合，验证表现即常量地板 |

### 5. 结构性根因

522 维异构特征（原子统计、键统计、MACCS 位、BRICS、头尾比、描述符等模块拼接）被当作 **522 个连续时间步** 逐维喂入 3 层 LSTM（64 隐单元、dropout 0.2）。MSE 损失下，该模型最易收敛到**"输出全局均值"的平凡均衡态**：残差即目标的固有噪声（val RMSE → 目标 std），梯度信号沿 522 步 × 3 层冲刷衰减，无法脱离均衡。这一退化与 Pi_CMC、AW_ST_CMC 等 target 上的 Transformer 表现同源——**序列化深度模型不适用于本项目"小样本 + 扁平异构特征"场景**。

### 6. 论文表述建议（面向审稿）

- **R² = −0.01 照抄**：可信、可复现、数学自洽，third data reviewer 用同一模型复算可得相同数值。
- **RMSE 勿写 0.0**：应写原始单位约 1.42×10⁻⁶ mol/m²（或缩放单位 ~2.13），并注明记录值 0.0 系 4 位小数舍入。
- **一句话归因**：模型退化为常量预测（预测方差仅为目标方差的 ~5×10⁻⁵），常量偏离测试均值，R² 略负于零。
