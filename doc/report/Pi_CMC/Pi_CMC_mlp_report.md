## 概述

MLP（多层感知机）是 10 个模型中唯一的**前馈全连接深度网络**（RNN/Transformer 为序列式深度模型）。架构为 `Linear → BatchNorm → GELU → Dropout` 重复堆叠 N 层，末层映射到单值输出，以 522 维特征向量整体作为输入（不做序列化）。深度网络对特征的**非线性组合与隐式高阶交互**建模能力强于树模型，是"手工特征 + 神经网络"路线的代表。

在 Pi_CMC 任务中，MLP 的 Test R² = 0.5402、Test RMSE = 4.8837，在 10 个模型中**排名第 8**。虽然仍是深度模型中的最优者（显著优于 RNN/Transformer），但相对树模型明显落后——Pi_CMC 的小样本（552 训练）使深度网络的过拟合风险放大。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载，与其余模型一致。
- **数据规模**：训练池 631 条（552 训练 + 79 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。

## 超参数与调优

采用 **Optuna 50 轮 × 5 折交叉验证**（TPE 采样器 + MedianPruner）。这是深度模型中唯一使用 Optuna 的（RNN/Transformer 用固定架构）。

**最优试验（Trial 25，CV RMSE = 3.6857）：**

| 参数 | 值 |
|------|-----|
| n_layers | 6 |
| hidden_dim | 143 |
| dropout | 0.088 |
| activation | **gelu** |
| learning_rate | 0.00203 |
| weight_decay | 8.97e-6 |
| batch_size | 49 |
| Best CV RMSE | 3.6857 |

**调优过程观察：**
- 最优解偏好**6 层深堆叠 + 较小隐藏层（hidden_dim=143）＋ GELU 激活 + 低 dropout（0.088）**，学习率收敛到 0.002 的量级。
- 后续试验（Trial 42~48）CV RMSE 稳定在 3.71~3.77，与最优解差距 < 0.08，说明搜索已收敛、解稳定；50 轮中约 20 轮被剪枝。
- 值得注意的是，MLP 的 **CV RMSE（3.6857）在 10 个模型中最低**，甚至优于榜首 XGBoost（4.0309）——但最终测试表现（4.8837）却显著恶化，说明小样本下 MLP 的 CV 优势未能泛化到测试集，这正是深度模型在本任务的根本困境。

## 训练过程

最终模型以最优参数在 552 条数据上训练，**早停在 epoch 280** 触发。训练约 280 个 epoch 表明网络需要较多迭代才能收敛；由于早停机制，最终以验证最优权重（而非末轮权重）作为交付模型。但验证集 RMSE（4.1786）与最终测试 RMSE（4.8837）之间存在明显差距，提示**测试分布与训练分布存在一定偏移**，深度网络对该偏移的鲁棒性弱于树模型。

> 说明：最终训练与调参在不同运行中执行（调参日志在 `Pi_CMC_mlp_tuning_20260806_174258`，本次为最终训练运行）。

Test MSE = 23.8501 与之印证。MLP 的 Test RMSE（4.8837）显著高于调参 CV（3.6857，差距约 32%）与验证 RMSE（4.1786），是树模型中常见的"测试优于 CV"现象的**反向版本**——深度网络在小样本 + 固定随机种子划分下的泛化稳定性明显不足。

## 特征重要性

MLP 为黑盒网络，日志未输出特征重要性。其输入为 522 维原始特征向量，重要特征需借助 **SHAP 的 KernelExplainer** 事后归因。基于其余树模型的一致性结论，可推断其预测主要由**原子聚合统计（Gasteiger 电荷类）与分子尺寸/疏水性描述符**驱动——这正是 XGBoost/CatBoost/HistGB 等模型共同指向的 Pi_CMC 主导特征。MLP 的 6 层深网络能隐式组合这些特征，但受限于样本量，未能像树模型那样稳定捕捉其规律。

## 结论与评价

**优点：**
- **深度模型中的最优者**：R² = 0.5402，显著优于 RNN（−0.0315）与 Transformer（−0.0663）。
- 使用 Optuna 充分调参（vs 固定架构的 RNN/Transformer），超参选择有依据；CV RMSE（3.6857）为全模型最低，说明在训练分布内部建模能力很强。
- 早停 + Dropout + weight_decay 三重正则。

**不足：**
- **泛化失败**：Test RMSE（4.8837）比 CV（3.6857）恶化 32%，排名第 8，被全部树模型反超——小样本（552）下深度网络的过拟合与测试分布偏移问题暴露无遗。
- 调参成本高（约 41 分钟），为树模型的数十倍。
- 黑盒模型，可解释性差；不提供不确定性估计（对比 NGBoost）。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 6 | HistGB | 4.5919 | 0.5935 |
| 7 | RandomForest | 4.7542 | 0.5642 |
| **8** | **MLP** | **4.8837** | **0.5402** |
| 9 | RNN | 7.3144 | −0.0315 |
| 10 | Transformer | 7.4369 | −0.0663 |

MLP 处于深度模型与树模型的分界点上：虽然显著优于另两个深度模型（RNN/Transformer），但在 Pi_CMC 上完全无法匹敌第一梯队树模型（XGBoost/CatBoost，R² ≈ 0.64）。在 522 维手工特征 + 552 训练样本的配置下，**深度网络路线在 Pi_CMC 上的性价比不敌树模型**；若坚持深度路线，需扩充数据或改用更强的特征自学习架构。
