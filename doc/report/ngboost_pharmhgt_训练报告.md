## 1. 实验概述

本实验使用 **NGBoost（Natural Gradient Boosting）** 概率梯度提升模型，结合 **PharmHGT 风格 522 维分子特征**，对表面活性剂的 **pCMC** 值进行**概率回归预测**。

**NGBoost 的核心特点**：

- **概率预测**：不同于传统回归模型输出单一预测值，NGBoost 输出完整的**概率分布**（Normal 分布的均值 ± 标准差）
- **自然梯度**：使用自然梯度（Natural Gradient）而非普通梯度来优化概率分布参数，对高维参数空间更高效
- **不确定性量化**：每个预测附带置信区间，可评估模型对每个样本的预测置信度
- **评分规则**：使用适当的评分规则（如 LogScore、CRPS）进行优化

### 5.2 概率预测解读

NGBoost 的独特优势：每个预测输出为一个高斯分布 `N(μ, σ)`：

```
预测 pCMC = μ ± σ
例如: 样本预测为 2.50 ± 0.14，表示 95% 置信区间约为 [2.22, 2.78]
```

- **平均预测标准差 = 0.1432**：模型对大多数样本的预测不确定性约为 ±0.14 个 pCMC 单位
- 这为该模型的实际应用提供了额外的**置信度信息**——知道哪些预测可靠、哪些不可靠

4. **MAE 偏高**（0.2853 vs LightGBM 0.2745）：NGBoost 的 LogScore 优化目标更侧重于整体分布的拟合质量，而非点估计精度

## 9. NGBoost 概率预测能力评估

### 9.1 优势

1. **不确定性量化**：每个预测附带标准差（平均 0.1432），可直接计算预测置信区间
2. **信息量丰富**：不仅告诉"预测值是多少"，还告诉"有多确信"
3. **自然梯度优化**：对概率分布参数的优化更高效稳定
4. **点估计性能不弱**：R²=0.8605 与 LightGBM 持平，在点估计任务上具有竞争力

### 9.2 局限性

1. **点估计精度上限**：概率模型在纯点估计任务上通常略逊于专门优化的点估计模型（如 CatBoost）
2. **训练速度较慢**：需要使用自然梯度计算，但 Optuna 50 trials 仍可接受
3. **特征重要性不直观**：因输出分布参数结构特殊，标准特征重要性方法不适用

### 9.3 应用场景建议

NGBoost 最适合 **需要预测置信度** 的场景：
- 安全关键领域：需要知道"这个预测是否可靠"
- 异常检测：预测不确定性大的样本可能是异常结构
- 主动学习：选择不确定性最大的样本进行标注
- 风险控制：基于置信区间而非点估计做决策
