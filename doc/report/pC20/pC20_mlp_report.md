## 概述

MLP（多层感知机）是 10 个模型中唯一的**前馈全连接深度网络**（RNN/Transformer 为序列式深度模型）。架构为 `Linear → BatchNorm → GELU → Dropout` 重复堆叠 N 层，末层映射到单值输出，以 522 维特征向量整体作为输入（不做序列化）。深度网络对特征的**非线性组合与隐式高阶交互**建模能力强于树模型，是"手工特征 + 神经网络"路线的代表。

在 pC20 任务中，MLP 的 Test R² = 0.8127、Test RMSE = 0.5168，**在 10 个模型中排名第 1，是 pC20 的最优模型**——这是本项目少有的深度模型全面胜出的 target。它同时验证了 pC20 结构-活性关系中存在树模型难以捕捉的非线性结构。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载，与其余模型一致。
- **数据规模**：训练池 564 条（493 训练 + 71 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。

## 超参数与调优

采用 **Optuna 50 轮 × 5 折交叉验证**（TPE 采样器 + MedianPruner）。这是深度模型中唯一使用 Optuna 的（RNN/Transformer 用固定架构）。

**最优试验（Trial 3，CV RMSE = 0.5062）：**

| 参数 | 值 |
|------|-----|
| n_layers | 4 |
| hidden_dim | 659 |
| dropout | 0.0232 |
| activation | **relu** |
| learning_rate | 0.00703 |
| weight_decay | 6.73e-4 |
| batch_size | 107 |
| Best CV RMSE | 0.5062 |

**调优过程观察：**
- Trial 0/1 表现极差（CV RMSE 1.42 / 2.63），原因是学习率过低（1.5e-5 / 3.5e-5）导致欠拟合；**搜索快速收敛到 lr ∈ [0.001, 0.009] 的合理区间**。
- 最优解显著偏好 **relu/leaky_relu 激活 + 中等隐藏层（400~700）+ 4 层左右**的结构，dropout 较低（0.02）以充分拟合仅有 564 条样本的任务。
- 最优 Trial 3 在 50 轮中一骑绝尘（CV RMSE 0.5062），其后仅有 Trial 25（0.5096）、Trial 33（0.5081）、Trial 40（0.5090）等逼近，整体搜索稳定、无过拟合于调参集。
- 50 轮中 20 轮被剪枝，占比 40%；后期大量试验因无法超过当前最优被早停，说明搜索后期已收敛。

## 训练过程

最终模型以最优参数在 493 条数据上训练，**早停在 epoch 465 触发**（日志最终记录 `Epoch 300/3000 — Val RMSE: 0.5312 (best: 0.4742)`，最终最优验证 RMSE 提升至 **0.4625**）。网络需要数百个 epoch 才能收敛，但由于早停机制未出现过拟合蔓延；最终以验证最优权重（而非末轮权重）作为交付模型。

> 说明：最终训练与调参在同一脚本中连续执行（调参日志末尾包含最终训练段），`pC20_mlp_tuning` 目录即本次调参过程存档。

## 特征重要性

MLP 为黑盒网络，日志未输出特征重要性。其输入为 522 维原始特征向量，重要特征需借助 **SHAP 的 KernelExplainer** 事后归因（`shap_mlp.py` 路径下可生成，但本次 pC20 运行未生成 SHAP 图）。基于其余模型的一致性结论，可推断其预测主要由 LogP、HeavyAtoms、MolWt、NAtoms 等全局疏水性/尺寸描述符驱动——这与 pC20（疏水尾越长、界面效率越高）的物理机制吻合。

## 结论与评价

**优点：**
- **pC20 最优模型**：R² = 0.8127、RMSE 0.5168，排名第 1，且较第 2 名 CatBoost（0.7237）领先近 0.09 个 R²，优势明显。
- 使用 Optuna 充分调参（vs 固定架构的 RNN/Transformer），超参选择有依据、结果可复现。
- 早停 + Dropout + weight_decay 三重正则，泛化稳健，Test 与 CV 指标吻合。

**不足：**
- 调参成本不低（约 32 分钟，虽低于 pCMC 任务的 90 分钟），仍显著高于多数树模型。
- 黑盒模型，可解释性差；MAE（0.3804）虽全模型最优，但绝对误差仍达 0.38 个 pC20 单位。
- 不提供不确定性估计（对比 NGBoost）。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| **1** | **MLP** | **0.5168** | **0.8127** |
| 2 | CatBoost | 0.6276 | 0.7237 |
| 3 | CIF (ExtraTrees) | 0.6422 | 0.7108 |

MLP 在 pC20 任务上以明显优势登顶，是**深度模型在此 target 胜出的关键证据**。RNN/Transformer 的垫底说明"能否胜出"取决于序列化方式与特征形态：MLP 以扁平 522 维整体输入，恰好契合手工特征的非序列本质；这也提示 pC20 的预测价值值得围绕 MLP 进一步挖掘。
