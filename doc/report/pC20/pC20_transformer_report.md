# Transformer 模型报告 — pC20 预测

## 报告信息

| 项目 | 内容 |
|------|------|
| 目标变量 | pC20（表面活性剂效率，log(1/C20)） |
| 运行目录 | `runs\pC20\pC20_transformer_20260806_150057` |
| 运行时间 | 15:00 ~ 15:09（约 9 分钟，固定架构训练，早停于 epoch 210） |
| 特征类型 | PharmHGT 522 维手工特征 |
| 报告生成日期 | 2026-08-07 |

## 概述

Transformer Encoder 是 10 个模型中三个深度模型之一。本项目将 **522 维特征向量重塑为序列 (batch, 522, 1)**，输入 3 层 Transformer Encoder（d_model=128、4 头自注意力、FFN 256、GELU），末层映射到单值输出——即"把特征当 token 序列"的序列式深度网络。自注意力机制理论上可对特征间关系做全局建模，但这以**足够大的训练数据**为前提。

在 pC20 任务中，Transformer 的 Test R² = 0.2297、Test RMSE = 1.0480，**在 10 个模型中排名垫底（第 10）**。pC20 训练池仅 564 条，远不足以支撑 Transformer 的参数量，这是其失利的根本原因。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练池 564 条（493 训练 + 71 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **输入重塑**：522 维 → (batch, 522, 1)，每维作为一个 token。

## 超参数与调优

本模型采用**固定架构，不进行 Optuna 调参**，超参数直接给定：

| 参数 | 值 |
|------|-----|
| Encoder 层数 | 3 |
| d_model | 128 |
| 注意力头数 | 4 |
| FFN 维度 | 256 |
| 激活函数 | GELU |
| learning_rate / weight_decay | 1e-3 / 1e-5 |
| batch_size | 16 |
| 最大 epoch | 500（早停） |
| 学习率调度 | CosineAnnealingLR |
| grad_clip | 5.0 |

**说明：** 与 RNN 相同，Transformer 未做超参搜索。d_model=128、4 头自注意力在 522 个 token 上产生大量可训练参数，而训练样本仅 493，参数量/数据量比例严重失衡。

## 训练过程

模型在 493 条数据上训练，**早停在 epoch 210 触发**（验证集 150 轮不改善即停）。收敛过程暴露了严重的训练不稳定性：

- Epoch 5~60：Val RMSE 从 1.157 降至 **0.9600（Epoch 60，最优验证点）**，短暂有效；
- Epoch 60 之后：验证 RMSE 在 1.0~1.6 之间**剧烈震荡**（如 Epoch 150 达 1.513、Epoch 155 达 1.602、Epoch 205 达 1.523），最优值 0.9600 此后 150 轮从未被刷新，最终触发早停。

这种"先下降后震荡恶化"的模式表明模型在小样本上**严重过拟合**，且 CosineAnnealingLR + 高容量自注意力的组合无法稳定收敛。最优验证 RMSE 0.9600 也远高于 MLP（0.4625）与 RNN（0.6843），从源头就限制了最终精度。

## 测试结果

| 指标 | 值 |
|------|-----|
| Test RMSE | **1.0480** |
| Test MAE | **0.8417** |
| Test R² | **0.2297** |
| Best val RMSE | 0.9600 |

> 说明：本模型训练脚本**未生成** pred_vs_true 预测-真值散点图与 SHAP 图（深度模型脚本无绘图输出）。如需可视化，可复用 `train_transformer_use_pharmhgt_features.py` 中加载的缓存特征另行绘制。

Test RMSE（1.0480）进一步高于验证 RMSE（0.9600），且 **Test R² 仅 0.2297**——模型几乎不具备预测能力（R² 接近 0 即相当于"预测均值"的基线水平）。Test MSE = 1.0982 与之印证。

## 特征重要性

Transformer 为黑盒注意力网络，日志未输出特征重要性，且深度模型脚本不生成 SHAP 图。基于其余模型的一致性结论，pC20 主要受 LogP、HeavyAtoms、MolWt 等疏水性/尺寸描述符驱动；Transformer 的问题不在特征信息缺失，而在**高容量自注意力在 564 条小样本上无法学习到稳定的特征-目标映射**。同为深度模型，MLP（R² 0.8127，扁平全连接）以低得多的参数量取得了全场最优，反衬出序列式 Transformer 在本任务中的结构性劣势。

## 结论与评价

**优点：**
- 具备全局自注意力建模能力，理论表达力最强（但小样本下无法兑现）。
- 早停机制有效防止了无界过拟合（epoch 210 及时截断）。

**不足：**
- **精度垫底（R² = 0.2297）**，在 10 个模型中排名第 10，是所有模型中唯一 R² < 0.3 的。
- 训练极不稳定：Epoch 60 后验证 RMSE 震荡至 1.6，早停虽触发但最优点已不佳。
- 参数量/数据量严重失衡（493 训练样本 vs 高容量注意力网络），无 Optuna 调参，可解释性弱。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 8 | HistGB | 0.7441 | 0.6116 |
| 9 | RNN | 0.8516 | 0.4913 |
| **10** | **Transformer** | **1.0480** | **0.2297** |

Transformer 在 pC20 上全面垫底，与 RNN 共同证明：**序列式深度模型不适用于本项目 522 维扁平手工特征**，尤其在仅 564 条样本下。Transformer 的价值应留给数据量充足（如上万级分子库）或真正序列化输入（SMILES token）的场景。在 pC20 任务中，深度模型的代表是 MLP——它用最简洁的架构取得了最优成绩，而 Transformer/RNN 的失败为"模型-数据-特征匹配"提供了反面教材。
