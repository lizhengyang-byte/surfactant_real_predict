# RNN (LSTM) 模型报告 — pC20 预测

## 报告信息

| 项目 | 内容 |
|------|------|
| 目标变量 | pC20（表面活性剂效率，log(1/C20)） |
| 运行目录 | `runs\pC20\pC20_rnn_20260806_145717` |
| 运行时间 | 14:57 ~ 14:59（约 2 分钟，固定架构 800 epoch 训练） |
| 特征类型 | PharmHGT 522 维手工特征 |
| 报告生成日期 | 2026-08-07 |

## 概述

RNN（LSTM，长短期记忆网络）是 10 个模型中三个深度模型之一。本项目将 **522 维特征向量重塑为序列 (batch, 522, 1)**，把每个特征维度当作一个时间步输入 3 层 LSTM，末层映射到单值输出——即"把特征当序列看"的序列式深度网络。与 MLP（扁平输入）不同，LSTM 会沿特征维引入隐式的"顺序依赖"，这与 522 维手工特征无天然顺序的本质存在错配。

在 pC20 任务中，RNN 的 Test R² = 0.4913、Test RMSE = 0.8516，在 10 个模型中排名第 9，仅优于 Transformer，是 pC20 上表现不佳的深度模型之一。

## 数据与方法

- **特征**：522 维 PharmHGT 风格特征，从缓存加载（`[Cache HIT]`），与其余模型一致。
- **数据规模**：训练池 564 条（493 训练 + 71 验证），测试集 70 条。
- **数据划分**：`train_test_split(0.125, random_state=42)`，固定随机种子。
- **输入重塑**：522 维 → (batch, 522, 1)，每维作为一个时间步。

## 超参数与调优

本模型采用**固定架构，不进行 Optuna 调参**（深度模型中的 RNN/Transformer 均如此），超参数直接给定：

| 参数 | 值 |
|------|-----|
| LSTM 层数 | 3 |
| hidden_dim | 64 |
| learning_rate | 1e-3 |
| weight_decay | 1e-5 |
| batch_size | 32 |
| epochs | 800 |

**说明：** 与 pCMC 任务的 RNN 相同，本模型未搜索超参数空间。固定 64 维隐藏状态对 522 步序列而言容量偏小，无法充分捕捉特征间的非线性关系，这也是其精度受限的先天因素之一。

## 训练过程

模型在 493 条数据上训练 **800 个 epoch**（固定轮数，无早停）。收敛曲线缓慢而震荡：

- Epoch 0~150：Val RMSE 稳定在 ~1.14~1.15，几乎无改善；
- Epoch 200 起进入下降通道（0.96 → 0.93 → 0.90），期间多次反弹（如 Epoch 250 回升至 1.05）；
- Epoch 650~800：Val RMSE 从 0.763 逐步降至 **0.6843（Epoch 800，最后一个 epoch）**。

最优验证 RMSE 0.6843 出现在**最后一轮**，说明 800 epoch 恰好踩在模型能力边界附近——若训练更长，验证指标仍有改善空间；但也暗示序列式 LSTM 在 522 步长任务上收敛极慢、容量利用不充分。

## 测试结果

| 指标 | 值 |
|------|-----|
| Test RMSE | **0.8516** |
| Test MAE | **0.5886** |
| Test R² | **0.4913** |
| Best val RMSE | 0.6843 |

> 说明：本模型训练脚本**未生成** pred_vs_true 预测-真值散点图与 SHAP 图（深度模型脚本无绘图输出）。如需可视化，可复用 `train_rnn_use_pharmhgt_features.py` 中加载的缓存特征另行绘制。

Test RMSE（0.8516）显著高于验证 RMSE（0.6843）约 0.17，**过拟合迹象明显**——LSTM 在 522 步序列上记住了训练集的模式，却未泛化到测试集。Test MSE = 0.7253 与之印证。

## 特征重要性

RNN 为黑盒循环网络，日志未输出特征重要性，且深度模型脚本不生成 SHAP 图。基于其余模型的一致性结论，可推断 pC20 主要受 LogP、HeavyAtoms、MolWt、NAtoms 等疏水性/尺寸描述符驱动；RNN 的问题不在于特征信息不足，而在于**序列式结构无法像 MLP 那样对 522 维特征做整体非线性变换**——同为深度模型，MLP（R² 0.8127）与 RNN（0.4913）的巨大差距直接印证了这一点。

## 结论与评价

**优点：**
- 具备序列建模能力，理论上可捕捉特征间隐式顺序关系（但 522 维手工特征并无真实顺序，此能力无处发挥）。
- 训练成本低（约 2 分钟），与固定架构、固定轮数的简单配置相匹配。

**不足：**
- **精度第 9（R² = 0.4913）**，在 10 个模型中倒数第 2，显著落后 MLP（0.8127）——序列式结构对 522 维扁平特征严重错配。
- Test（0.8516）与验证（0.6843）差距约 0.17，过拟合明显，泛化失败。
- 无 Optuna 调参、无早停、无特征重要性输出，可解释性与可控性均弱。

**横向定位（10 个模型中按 Test RMSE 排序）：**

| 排名 | 模型 | Test RMSE | Test R² |
|------|------|-----------|---------|
| 7 | LightGBM | 0.6919 | 0.6643 |
| 8 | HistGB | 0.7441 | 0.6116 |
| **9** | **RNN** | **0.8516** | **0.4913** |
| 10 | Transformer | 1.0480 | 0.2297 |

RNN 在 pC20 上是明确的反面教材：**"把特征当序列"的建模假设在本项目 522 维手工特征上不成立**。pC20 的深度模型胜出应由 MLP 的扁平全连接结构承担，RNN/Transformer 的垫底则说明序列式深度模型不适用于此类特征形态。除非未来改用真正的分子序列输入（如 SMILES token 序列），否则不建议继续投入 RNN 方向。
