# RNN-LSTM + PharmHGT 特征 表面活性剂 pCMC 预测 — 训练报告

> **报告生成日期**: 2026-07-23

> **模型**: RNN-LSTM（3 层双向 LSTM）  
> **特征**: PharmHGT 风格 522 维分子特征  
> **目标变量**: pCMC (log CMC，临界胶束浓度对数值)

## 1. 实验概述

本实验使用 **RNN-LSTM**（长短时记忆网络）深度序列模型，结合 **PharmHGT 风格 522 维手工分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。

**核心设计理念**：将 522 维特征向量视为 **522 个时间步 × 1 个特征** 的序列，用 LSTM 捕捉维度间的**顺序依赖关系**。这与 MLP（特征组合）和树模型（特征分裂）的表征方式有本质区别。

实验流程包括：

1. 特征提取（从 SMILES 计算 522 维特征，缓存命中）
2. 训练/验证集划分（1,053 训练 + 151 验证）
3. RNN-LSTM 模型训练（固定参数，早停 50 轮）
4. 测试集评估（140 个样本）
5. 模型保存

## 3. 模型架构

### 3.1 网络结构

```
输入 (batch, 522)
    ↓ unsqueeze(-1)
(batch, 522, 1)
    ↓
LSTM (3 层)
  input_size=1, hidden_size=64, batch_first=True
  ↓
取最后时间步输出 (batch, 64)
    ↓
Linear(64 → 1)
    ↓
输出 (batch,) — pCMC 预测值
```

### 3.2 模型参数

| 参数 | 值 |
|------|-----|
| 输入序列长度 | **522**（特征维度数） |
| 每个时间步特征 | **1**（单个维度值） |
| LSTM 层数 | **3** |
| 隐藏层维度 | **64** |
| LSTM 层间 Dropout | **0.2** |
| 输出层 | Linear(64 → 1) |
| **总参数量** | **~140K**（约 14 万参数） |

### 3.3 训练配置

| 配置项 | 值 |
|--------|-----|
| 优化器 | **AdamW** |
| 学习率 | **1e-3** |
| 权重衰减 | **1e-5** |
| 批次大小 | **32** |
| 最大轮数 | 800 |
| 早停轮数 | 50 |
| 验证评估频率 | 每 5 个 epoch |
| 学习率调度 | 无（固定学习率） |

### 3.4 架构设计要点

1. **序列化表征**：将 522 维扁平特征向量重塑为 `(522, 1)` 序列，LSTM 逐时间步处理每个特征维度，捕捉维度间的顺序依赖

2. **3 层 LSTM 堆叠**：多层 LSTM 可学习层次化的特征依赖关系，底层关注相邻维度的局部模式，高层关注跨维度的全局依赖

3. **小隐藏维度（64）**：相对于 MLP 的 512，LSTM 使用较小的 64 维隐藏状态，限制模型容量（约 14 万参数，仅为 MLP 的 1/13），防止在小数据集上过拟合

4. **最后时间步输出**：仅取序列最后一个时间步的隐藏状态作为全局表征，通过 Linear 层映射到预测值

### 4.1 训练超参数

| 超参数 | 值 | 设定理由 |
|--------|-----|---------|
| LSTM 层数 | 3 | 足够的深度建模层次化依赖 |
| 隐藏维度 | 64 | 中等容量，防止过拟合 |
| Dropout | 0.2 | 层间正则化，高于 MLP 的 0.1 |

| 权重衰减 | 1e-5 | 轻度 L2 正则化 |

| 指标 | **RNN-LSTM** | **MLP** | 差距 |

### 5.4 与所有模型对比

| 模型 | R² | RMSE | MAE | 最佳 Val RMSE |
|------|:---:|:----:|:----:|:-------------:|
| CatBoost 🥇 | **0.8733** | 0.3955 | 0.2669 | **0.0494** |
| MLP 🥈 | **0.8679** | 0.4039 | **0.2578** | 0.0557 |
| XGBoost 🥉 | 0.8706 | 0.3998 | 0.2695 | — |

**对比分析**：

1. **RNN-LSTM 的 R² 远低于其他模型**（0.7587 vs 其他 ≥ 0.86）：将 522 维特征强制建模为时间序列的假设——维度间存在有意义的顺序依赖——在本任务中**不成立**

2. **验证集表现良好但测试集差距大**：最佳 Val RMSE=0.1447（与 XGBoost 接近），但 Test RMSE=0.5459 远高于其他模型，说明存在较为严重的**过拟合**或**分布偏移**

3. **与 MLP 的核心差异**：MLP 将 522 维特征视为**无序集合**（全连接层可学习任意特征组合），而 RNN 将其视为**有序序列**（LSTM 偏重相邻位置的顺序模式）。性能差距（R² 0.7587 vs 0.8679）表明特征维度的排列顺序不蕴含有用的序列信息

4. **参数量虽小但过拟合仍严重**：尽管 RNN-LSTM 仅 14 万参数（远小于 MLP 的 184 万），测试集泛化能力仍然最弱。问题不在于模型容量，而在于**序列建模假设本身不适合该特征**

## 6. 性能差距原因分析

RNN-LSTM 在本任务中表现不佳的深层原因：

### 6.1 特征排列的任意性

522 维特征的排列顺序（原子聚合→键聚合→MACCS→BRICS→表面活性剂→描述符）是**人为设定**的，不具有物理或化学意义上的"序列逻辑"：
- 第 0-219 维是原子特征统计量，相邻维度间的数值变化**不蕴含有意义的"局部模式"**
- 第 220-275 维是键特征统计量，与前面的原子特征之间**无自然的"序列过渡"**
- LSTM 的序列建模优势（如时序建模、语言建模）依赖于相邻时间步之间的**语义连续性**，而这在扁平分子特征中不存在

### 6.2 序列长度过长

522 个时间步对于 LSTM 而言是**非常长的序列**：
- 梯度在 522 步的反向传播中容易衰减（即使使用了 LSTM 的门控机制）
- 序列中期的特征信息可能被遗忘
- 模型可能过于关注序列末尾的少数维度

### 6.3 适合 RNN 的场景

RNN-LSTM 更适合**天然具有顺序结构**的数据，如：
- 分子 SMILES 字符串本身（字符级序列）
- 分子图上的原子遍历序列
- 分子动力学模拟的时间序列
- 但**不适合**将已经聚合好的 522 维统计特征再作为序列处理

### 核心结论

1. **RNN-LSTM 不适合 PharmHGT 特征的表征方式**：将 522 维聚合特征强制序列化处理，导致 R² 仅为 0.7587，远低于其他模型

2. **序列建模假设失效**：特征维度间的排列顺序不蕴含有意义的序列信息，LSTM 的顺序依赖建模能力在此任务中成为累赘

3. **验证集欺骗性**：RNN-LSTM 的最佳 Val RMSE=0.1447 看似优秀，但测试 R²=0.7587 说明验证集上的好表现未能迁移到测试集

4. **RNN-LSTM 更适合处理原始分子序列**（如 SMILES 字符串的字符级序列或分子图的遍历序列），而非预计算好的统计聚合特征
