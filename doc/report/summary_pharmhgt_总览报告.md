# 表面活性剂 pCMC 预测 — 全模型总览报告

> **报告生成日期**: 2026-07-23  
> **特征**: PharmHGT 风格 522 维分子特征  
> **目标变量**: pCMC (log CMC，临界胶束浓度对数值)  
> **模型总数**: 9 个（6 种算法类别）

## 1. 项目概述

本项目使用 **PharmHGT 风格 522 维手工分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。共完成 **9 个模型**的训练与评估，涵盖 **Boosting、Bagging、深度学习、概率 Boosting** 四大算法类别。

### 1.1 数据概况

| 数据集 | 样本数 | 说明 |
|--------|--------|------|
| 训练集 | 1,204 | 含 1,053 训练 + 151 验证（0.875/0.125 划分） |
| 测试集 | 140 | 独立测试集 |
| **总计** | **1,344** | |

### 1.2 特征构成

| 特征模块 | 维度 | 说明 |
|---------|------|------|
| 原子聚合特征 (atom_agg) | 220 | 55 维原子特征 × 4 统计量 |
| 键聚合特征 (bond_agg) | 56 | 14 维键特征 × 4 统计量 |
| MACCS 指纹 | 194 | 药效团特征 |
| BRICS 碎片 | 34 | 反应性碎片 |
| 表面活性剂类型 | 4 | 阴/阳/非/两性 one-hot |
| 头基/尾链比例 | 2 | head_ratio, tail_ratio |
| 分子描述符 | 12 | RDKit 全局描述符（归一化） |
| **总计** | **522** | |

## 4. 关键发现

### 4.1 MLP + Optuna 调参 = 质的飞跃

MLP 从第一版固定参数（R²=0.8679）到 Optuna 调参版（R²=0.9052）实现了 **+4.3 个百分点** 的绝对提升，是唯一突破 **R²>0.90** 的模型。

**最佳架构**由 Optuna 搜索确定：

| 超参数 | 第一版（固定） | 第二版（Optuna） |
|--------|:------------:|:---------------:|
| 层数 | 4 | **3** |
| 隐藏维度 | 512 | **990** |
| Dropout | 0.1 | **0.267** |
| 学习率 | 1e-3 | **0.00673** |
| 权重衰减 | 1e-6 | **1.06e-4** |
| 批次大小 | 64 | **95** |
| **Test R²** | 0.8679 | **0.9052** |

### 4.2 Boosting 家族整体表现优异

所有 Boosting 模型（CatBoost/XGBoost/LightGBM/HistGB）均达 R²≥0.83，其中：
- **CatBoost** 以最少调参成本（50 trials, CPU）取得 R²=0.8733，**性价比最高**
- **XGBoost** 投入最大调参力度（200 trials + Holdout 二次筛选），性能与 CatBoost 持平
- **LightGBM** 以最快速度（~4min）取得 R²=0.8602，适合快速迭代

### 4.3 CIF 是 Bagging 家族的黑马

CIF（条件推断森林）以 R²=0.8751 大幅超越标准 RandomForest（0.8128），差距达 **6.2 个百分点**。其核心优势：
- **统计显著性分裂**：对 522 维高维特征进行无偏特征选择
- **bootstrap=False**：不使用自助采样，降低偏差
- **调参仅需 ~5 分钟**，性价比极高

### 4.4 领域知识特征一致重要

在所有模型中，**LogP** 始终是最重要的单一特征，其次是 **tail_ratio**（疏水尾链占比）、**HeavyAtoms** 和 **MolWt**。这验证了：
- 亲水-疏水平衡对 CMC 的核心决定作用
- PharmHGT 风格特征工程（头基/尾链检测）的有效性
- RDKit 全局描述符在高维特征中仍占据主导地位

### 4.5 RNN-LSTM 的序列假设不适应该特征

将 522 维扁平特征向量视为 522 个时间步的序列进行 LSTM 建模，导致 R² 仅为 0.7587。特征维度间的**排列顺序不蕴含有意义的序列信息**，RNN 更适合 SMILES 字符串等天然序列输入。

## 5. 模型推荐

### 场景化选型建议

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 🎯 **追求最高精度** | **MLP（Optuna 调参版）** 🏆 | R²=0.9052，远领先于其他模型 |
| ⚡ **快速验证/迭代** | **LightGBM** | ~4min 完成调参+训练，R²=0.8602 |
| 💰 **性价比最优** | **CIF** | ~5min 调参，R²=0.8751，无需 GPU |
| 🔬 **需要预测置信度** | **NGBoost** | 唯一输出概率分布（均值±标准差）的模型 |
| 📊 **需要可解释性** | **CatBoost / CIF** | 提供特征重要性排名，领域知识可验证 |
| 🔄 **生产部署（CPU）** | **CatBoost** | 推理速度最快，CPU 友好，无需 GPU |
