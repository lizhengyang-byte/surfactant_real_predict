# CatBoost + PharmHGT 特征 表面活性剂 pCMC 预测 — 训练报告

> **报告生成日期**: 2026-07-22  
> **运行时间戳**: 2026-07-22 18:16:38  
> **模型**: CatBoost (Categorical Boosting)  
> **特征**: PharmHGT 风格 522 维分子特征  
> **目标变量**: pCMC (log CMC，临界胶束浓度对数值)

---

## 1. 实验概述

本实验使用 **CatBoost** 梯度提升树模型，结合 **PharmHGT 风格 522 维手工分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。实验流程包括：

1. 特征提取（从 SMILES 计算 522 维特征，含缓存命中）
2. 训练/验证集划分（1,053 训练 + 151 验证）
3. Optuna 超参数优化（50 次试验 × 5 折交叉验证）
4. 最终模型训练（全量训练数据 + 早停）
5. 测试集评估（140 个样本）
6. 特征重要性分析

### 3.3 优化过程

在 50 次试验中，**最佳试验为第 17 次**，CV RMSE = **0.462177**。

**全部 50 次试验的 CV RMSE 分布**：

```
CV RMSE 分布区间：
  < 0.47:  19 次 (38%)   ← 最佳区域
  0.47-0.50: 22 次 (44%)
  0.50-0.60: 5 次 (10%)
  ≥ 0.60:   4 次 (8%)    ← 表现较差的异常试验
```

**优化过程分析**：
- 最佳值 **0.4622** 在第 17 次试验中找到，后续试验虽接近（如 Trial 33: 0.4623, Trial 45: 0.4625）但未能超越
- CV RMSE 的分布集中在 0.46-0.50 区间，表明搜索空间设置合理，大多数参数组合表现稳定
- 有 4 次试验（Trial 3: 0.622, Trial 7: 0.608, Trial 35: 0.675, Trial 40: 0.598）表现明显较差，可能是不利参数组合导致的欠拟合

### 3.4 超参数重要性分析

CatBoost 训练日志提供了各超参数的重要性分数：

| 排名 | 超参数 | 重要性 | 说明 |
|------|--------|--------|------|
| **1** | `one_hot_max_size` | **0.3189** | 类别特征 one-hot 编码上限 — **最重要参数** |
| **2** | `l2_leaf_reg` | **0.2358** | L2 正则化强度 |
| **3** | `min_data_in_leaf` | **0.1356** | 叶节点最小样本数 |
| 4 | `learning_rate` | 0.1057 | 学习率 |
| 5 | `iterations` | 0.0897 | 迭代次数 |
| 6 | `random_strength` | 0.0503 | 分裂点随机噪声 |
| 7 | `border_count` | 0.0445 | 特征分桶数 |
| 8 | `depth` | 0.0079 | 树深度 — **重要性最低** |
| 9 | `bagging_temperature` | 0.0063 | Bagging 温度 |
| 10 | `leaf_estimation_iterations` | 0.0053 | 叶值估计迭代 |

**关键解读**：

1. **`one_hot_max_size` 是最关键的超参数**（重要性 0.319）：522 维特征中的 one-hot 编码原子/键特征（如原子序数 16 维、杂化方式 5 维等）与 CatBoost 的类别特征处理机制交互密切，该参数控制何时将类别特征转换为 one-hot 编码，对模型性能影响最大。

2. **`l2_leaf_reg` 和 `min_data_in_leaf` 合计占 37% 重要性**：正则化和叶节点约束是控制 CatBoost 过拟合的核心手段，对于 522 维高维特征输入尤为重要。

3. **`depth` 重要性仅 0.008**：在最佳值 `depth=5` 下，树深度的微小变化对性能影响不大，CatBoost 的对称树（oblivious tree）结构本身对深度不敏感。

4. **`bagging_temperature` 最佳值 9.027**：接近上限 10.0，表明强 Bagging（接近完全贝叶斯 Bagging）有利于提升泛化，这与 522 维特征的高维度特性一致。

### 3.5 最佳超参数解读

最佳参数组合揭示的模型行为特征：

1. **浅树深度** (`depth=5`)：CatBoost 的对称树在 `depth=5` 时可产生 2⁵=32 个叶节点，结构简洁、泛化性好
2. **中等学习率** (`learning_rate=0.0366`) + **适中迭代** (`iterations=1566`)：平衡了训练速度和模型精度
3. **较强正则化** (`l2_leaf_reg=5.96`, `min_data_in_leaf=42`)：对 522 维高维特征施加了有效约束，防止过拟合
4. **高 `one_hot_max_size=43`**：允许更多的类别特征（≤43 个类别）以 one-hot 形式编码，CatBoost 默认对低基数类别特征使用 ordered TS 编码，提高 one-hot 上限意味着更多特征被以独立维度处理
5. **强 Bagging** (`bagging_temperature=9.03`)：接近完全贝叶斯 Bagging，每棵树使用不同的子样本，增强模型多样性

## 9. 结论与展望

### 9.1 主要结论

1. **CatBoost + PharmHGT 522 维特征** 在表面活性剂 pCMC 预测任务上取得了当前最优结果：**R²=0.8733, RMSE=0.3955**，优于 LightGBM 的 R²=0.8602。

2. **超参数 `one_hot_max_size` 是最关键参数**（重要性 0.319），对高维分子特征的编码方式影响最大。

3. **CatBoost 的对称树结构** 在 522 维特征任务上表现出更好的泛化能力，验证集 RMSE 持续下降至 0.0494 且未过拟合。

4. **LogP 是绝对最重要的分子描述符**（两个模型均列为第 1），印证了亲水-疏水平衡对表面活性剂 CMC 的核心决定作用。

5. **领域知识特征（tail_ratio、head_ratio）在两模型中均进入 Top-20**，验证了表面活性剂领域特征工程的有效性。

### 9.2 改进方向

1. **CatBoost 训练可尝试更多迭代**：最佳模型在 2,999 轮时验证误差仍在下降，可尝试将 `iterations` 上限提升至 5,000 以上。

2. **模型集成**：CatBoost（R²=0.8733）+ LightGBM（R²=0.8602）的加权平均或 Stacking 集成有望进一步提升。

3. **特征选择优化**：基于 CatBoost 的特征重要性，可尝试移除低重要性特征（如 bond_agg、BRICS），减少噪声。

4. **超参数搜索扩展**：当前 50 次试验中最佳值仍有提升空间（Trial 17→Trial 33 差值仅 0.0001），可增加试验次数至 100-200。

5. **与其他模型对比**：结合项目中的 XGBoost、MLP、RNN、Transformer 结果，进行全面的模型对比分析。
