## 1. 实验概述

本实验使用 **HistGradientBoosting**（sklearn 的直方图梯度提升实现）结合 **PharmHGT 风格 522 维分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。

HistGradientBoosting 是 LightGBM 风格基于直方图的梯度提升算法在 sklearn 中的官方实现（`HistGradientBoostingRegressor`），具有以下特点：

- 使用直方图分桶加速训练（`max_bins` 控制分桶数）
- 原生支持类别特征
- 内置 early-stopping
- 相比 LightGBM 更加轻量，无需额外依赖

4. **迭代轮数少**（618 vs 1972/1566）：更激进的 learning_rate（0.069）和更少的迭代可能限制了模型容量

### 6.3 独特发现

**HistGB 特征重要性的特别之处**：

1. **排列重要性可量化每个特征对 R² 的绝对贡献**（单位是 R² 的下降量），比树模型的 `weight`/`gain` 重要性更具可解释性

2. **LogP 的重要性 0.5394**：单独打乱 LogP 会使模型 R² 从 0.828 降至约 0.289，解释了超过 **65%** 的模型预测能力，是绝对主导特征

3. **HeavyAtoms 的重要性 0.3205**：单独打乱会使 R² 降至约 0.508

4. **brics_5 第 20 名**：这是 BRICS 碎片模块在所有模型中**首次进入 Top-20**（CatBoost/LightGBM/MLP/XGBoost 中均未出现）

5. **LogP + HeavyAtoms + MolWt 三者合计重要性 0.999**：几乎等于其他 17 个特征之和，说明 HistGB 的预测主要依赖分子大小和疏水性描述符
