# LightGBM + PharmHGT 特征 表面活性剂 pCMC 预测 — 训练报告

> **报告生成日期**: 2026-07-22  
> **运行时间戳**: 2026-07-22 18:04:32  
> **模型**: LightGBM (Light Gradient Boosting Machine)  
> **特征**: PharmHGT 风格 522 维分子特征  
> **目标变量**: pCMC (log CMC，临界胶束浓度对数值)

---

## 1. 实验概述

本实验使用 **LightGBM** 梯度提升树模型，结合 **PharmHGT 风格 522 维手工分子特征**，对表面活性剂的 **pCMC** 值进行回归预测。实验流程包括：

1. 特征提取（从 SMILES 计算 522 维特征，含缓存命中）
2. 训练/验证集划分（1053 训练 + 151 验证）
3. Optuna 超参数优化（50 次试验 × 5 折交叉验证）
4. 最终模型训练（全量训练数据 + 早停）
5. 测试集评估（140 个样本）
6. 特征重要性分析

### 3.3 优化过程

在 50 次试验中，最佳试验在第 **16 次** 找到：

```
Trial 16: CV RMSE = 0.4818
Boosting type: gbdt（非 dart，因此未使用 drop_rate / max_drop / skip_drop）
```

**优化过程趋势分析**：
- 早期试验（Trial 0-5）的 CV RMSE 从 2.07 快速下降至 0.51，说明 TPE 采样器快速定位到了有希望的区域
- 第 16 次试验达到最优 0.4818，后续试验虽接近但未能超越
- 多个试验被 `MedianPruner` 修剪（Trial 6, 7, 29, 38, 40），表明这些参数组合在早期迭代中表现明显低于中位数
- **最优 boosting_type 为 `gbdt`**，表明标准的梯度提升决策树对本任务优于带 Dropout 的 DART

### 3.4 最佳超参数解读

最佳参数揭示的模型行为特征：

1. **中等树深度** (`max_depth=10`)：适中复杂度，不过深亦不过浅
2. **较少叶子节点** (`num_leaves=31`)：与 `max_depth=10`（理论上最多 2^10=1024 叶）相比远低，说明 LightGBM 的 leaf-wise 生长被有效约束
3. **低学习率** (`learning_rate=0.0384`) + **较多迭代** (`n_estimators=1972`)：典型的长训练策略，有利于细致拟合
4. **高列采样** (`colsample_bytree=0.987`)：几乎使用全部特征，说明大部分特征对预测有贡献
5. **低正则化强度** (`reg_alpha=1.27e-8`, `reg_lambda=5.95e-5`)：L1/L2 惩罚极小，模型倾向于使用更多特征
6. **低 `min_child_samples=13`**：允许叶子节点较少样本，模型可学习更细粒度的模式

## 5. 测试集评估

| **Test MSE** | **0.1727** |
| **Test RMSE** | **0.4155** |
| **Test MAE** | **0.2745** |

### 5.2 指标解读

- **R² = 0.8602**：模型解释了测试集 86% 的方差，表明预测值与真实值具有高度线性相关性
- **RMSE = 0.4155**：预测的平均误差约为 0.42 个 pCMC 单位
- **MAE = 0.2745**：预测的绝对误差中位数约为 0.27 个 pCMC 单位，小于 RMSE，说明误差分布存在一定长尾（少数样本预测偏差较大）
- **MAE < RMSE** 的典型关系表明误差分布有右尾，存在少量预测较差的样本

### 6.2 重要性结构分析

**特征模块贡献分布**：

| 模块 | Top-20 中特征数 | 代表性特征 |
|------|----------------|-----------|
| 分子描述符 | 5 | LogP, MolWt, RotBonds, TPSA, HeavyAtoms |
| 表面活性剂特征 | 2 | tail_ratio, head_ratio |
| 原子聚合特征 | 13 | atom_mean_*, atom_std_* |

**关键发现**：

1. **LogP 是最重要的单一特征**（534 分）：表面活性剂的亲水-疏水平衡（HLB）直接由 LogP 反映，这与表面化学领域知识高度一致。

2. **尾链比例 (tail_ratio) 仅次于 LogP**（504 分）：疏水尾链长度是决定 CMC 的核心因素，特征工程中通过 DFS 检测最长碳链的方法是有效的。

3. **头基比例 (head_ratio) 排名第 6**（288 分）：亲水头基大小同样关键，与 tail_ratio 共同构成表面活性剂的核心结构描述。

4. **分子描述符整体贡献突出**：LogP、MolWt、RotBonds、TPSA、HeavyAtoms 共 5 个描述符进入 Top-20，说明分子全局性质对 pCMC 预测至关重要。

5. **原子聚合特征中原子质量 (atom_mean_35/atom_std_35) 和重原子邻居数 (atom_mean_54/atom_std_54) 最重要**：表明分子大小和原子连接性对表面活性行为有显著影响。

6. **MACCS 指纹和 BRICS 碎片未进入 Top-20**：说明官能团级和碎片级特征对树模型的贡献相对较小，可能是信息被分子描述符和原子聚合特征所覆盖。

## 9. 结论与展望

### 9.1 主要结论

1. **LightGBM + PharmHGT 522 维特征** 在表面活性剂 pCMC 预测任务上取得了 **R²=0.8602** 的优异表现，证明该特征工程策略与树模型的结合是有效的。

2. **领域知识特征（LogP、tail_ratio、head_ratio）占据重要性前三**，验证了表面活性剂领域知识（亲水-疏水平衡、尾链长度、头基大小）对 CMC 预测的核心作用。

3. **Optuna 自动调参成功**找到了合理的参数组合（gbdt, max_depth=10, num_leaves=31, lr=0.0384），CV RMSE=0.4818，最终模型验证 RMSE 降至 0.1562。

4. **训练收敛良好**，1,024 轮后早停触发，未出现明显过拟合（验证 RMSE 持续下降至 0.1562）。

### 9.2 改进方向

1. **进一步优化特征选择**：尝试移除低重要性特征（如 MACCS、BRICS），或仅保留 Top-K 特征，可能进一步提升泛化能力。

2. **集成学习**：将 LightGBM 与 CatBoost、XGBoost 进行模型集成（Stacking / Weighted Averaging），有望进一步提升预测精度。

3. **深度学习对比**：参考项目中的 MLP、RNN-LSTM、Transformer 结果，对比不同架构对 522 维特征的建模能力。

4. **误差分析**：对测试集中预测偏差较大的样本进行结构分析，识别模型盲区（如特殊类型的表面活性剂结构）。
